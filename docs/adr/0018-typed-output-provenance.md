# ADR-0018：已核验写入结果到原文的类型化关联

日期：2026-10-28。状态：接受，实施中。关联 FR-02、FR-03、FR-08、FR-09、FR-10、FR-11、FR-12、ENG-01；延续 ADR-0015、0016、0017。

## 复用调查与工程自审

固定上游已经持久保存 request_id 对应的 write_outcome，Core 任务保存原生 raw／memory ID，Hub 保存对应 Event。继续复用这些权威事实及既有成功结果核对，不按文本、来源标记或向量相似度猜关联。memory_operations_v2 有按 memory_id 的索引，但受可关闭的审计开关控制，写入错误也可被吞掉，且 coding writer 不写该表；不能用它承担所有分支的来源索引。SDK trace 也不能承担长期来源。

Core 回执丢失 ordinary／working／coding 及经验／事实类型，SDK productivity 结果又没有 variant；同一原生 ID 可出现在两个变体中。补丁在 SDK 已选定 writer 后把实际 variant 加入成功结果，并随原有 write_outcome 持久保存。旧结果仅在跨变体唯一存在时恢复类型，歧义明确拒绝。

SDK 改为与 Core 一同从 manifest 固定源码及补丁构建；本地 editable、镜像自足安装，构建工具固定版本，其他运行依赖不变。实际执行测试另外发现 Core 向完成清理传入已退役 Evidence 门面；同一最小补丁改为既有 SDK 暂存存储，保留清理语义。

这是实现者对架构、失败路径、测试和性能的自审，未启动委派，也不宣称独立同行审查。

## 数据与完成次序

在现有配置库增加独立 `cmh_lineage_schema=1`、`cmh_event_outcomes` 和 `cmh_event_output_links`，只保存已核验关系及其摘要，不复制正文、语义内容或处理状态机。输出键区分普通 raw、普通 memory，以及 working／coding 的经验／事实，索引支持按类型和 ID 查来源；一个输出可关联多轮事件，旧关系不会因同 ID 更新而被覆盖。

```text
SDK 成功持久化结果
 -> 核对原 Event、冻结输入、request/user/agent/session/operation
 -> 核对结果中全部输出存在性和类型／归属
 -> 同一配置事务保存完整关系（包括显式零产出）
 -> Core 原队列提交 completed 回执
```

给 Core 增加默认关闭的可选结果观察回调，位置在 SDK 写入返回后、任务完成前。回调失败沿用已有 unknown 路径，不能重发模型调用。未知结果核对恢复也先保存关系再完成；关系已保存而队列提交失败时，重复核对幂等。原文和写入结果不匹配则拒绝，不能修改归档来适配错误结果。

旧已完成任务通过现有周期核对入口分批补关联，利用归档 Event 重建已清理的冻结输入并查询原 write_outcome，不调用模型。无终态结果、内容已缺失或身份不符时保留待核对，不记录“无产出”。按稳定回执顺序轮换，坏任务不能饿死后续任务；完整写入关系在单事务提交，禁止半条关联集合。

新增表不改变接纳 schema 2 或协议 v1，启动只创建全新关系扩展；半套／未知版本拒绝，不删表重建。旧镜像会忽略新增关系，新版补核对旧镜像期间的任务，因此本变更不提供原文格式的下迁移，也不降低现有治理权威。

## 读取、权限与边界

统一读取在确认实际输出归属后补充 `cmhe:` 来源引用；普通 SDK 自身 raw 引用继续保留。用户仍须 history:read 才能获取原文。来源关联以一轮输入为粒度，上游未提供逐句证据时不伪造更精细关系。所有返回前继续复核项目授权及治理；后端损坏或关系原文校验失败不能当作空列表。

引用数量仍按原合同限制并报告截断，不能因为旧结果暂未补齐就宣称空引用代表没有来源。本阶段保存直接产出和历史更新输入关系；完整演化、共享摘要、fact_link、经验事实互链及治理范围合并继续实现，普通引用展示不能替代完整删除计划。

配置卷继续与 data／governance 共同备份和治理。后续彻底删除须覆盖关系索引、结果回执及其摘要，忘记／恢复抑制规则不变。现有未执行治理意图仍隔离实例。

## 验收

覆盖普通 raw／memory、两个 productivity 变体及两种输出；同原生 ID 的类型隔离；零产出；旧结果唯一恢复／歧义拒绝；多轮更新保留所有来源；回调失败进入 unknown 并由核对恢复；事务失败没有部分关系；清理后补核对、进程重启；项目隔离和权限变化；损坏原文、错误结果身份和缺失输出拒绝。保留上游队列、bridge 和 SDK 路由回归，进行安装／NAS 合成验证。真实外部模型质量与六客户端接续分别验收。
