# ADR-0005：本地凭证过滤与持久投递边界

日期：2026-10-23。状态：分步实现中。关联 FR-02、FR-06、FR-07、FR-08、ENG-01。

## 复用证据

固定上游 `b7d9f0e` 的 `one_memory/input_sanitization.py` 提供六类文本凭证过滤及来源区间，直接调用其 `sanitize_model_input`，保留原测试。其规则未覆盖完整 Cookie、中文凭证标签、递归元数据及更多凭证字段；Hub 增加这些出站边界规则，不复制原有六套实现。

`memory_server/durable_queue.py` 管理 NAS 上已接纳的模型处理任务，依赖 Core 数据库、写入合同及 lease；`change_outbox.py` 是暂停自动生产的旧变更通知，仅保存 evidence ID 和 permission epoch，不保存离线待上传事件。两者不能作为 Mac 上独立、先过滤的网络投递队列。新增本地 SQLite 投递库只负责保存、重试选取与接纳回执；NAS 处理继续复用上游队列，不创建第二套模型任务调度。

## 本地处理顺序与协议

`授权来源 → 解析 → 内存中凭证过滤 → 验证事件合同 → 本地持久队列 → 后续认证传输`。本批不接入日常 Agent、不读取真实历史、不发送网络请求。附加的诊断／状态只返回计数和固定错误码，不含正文、路径或凭证。

事件 v1 使用服务器 instance/device/source/project 身份及本地稳定 conversation/record UUID；外部 Agent 名称、原始路径、原生会话 ID 不能直接充当协议身份。适配器随后维护本地映射。事件 UUID 是重试身份，record revision 标识原始记录修订；同一事件 UUID 的不同正文拒绝覆盖。全局 scope 必须明确标为 `global`。正文和所有自由元数据置于 `content`，统一递归过滤；顶层字段严格白名单。

过滤器复用上游文本规则，补充 Authorization/Cookie、中文密码与密钥标签、嵌套敏感字段、URL 凭证与查询参数以及已知凭证格式。可注入只存在内存中的已知凭证列表，帮助清除未带标签的本机凭证。过滤所有字符串及字典键；键冲突、异常类型、超限／过深、不可解析媒体和可隐藏标签的控制字符直接拒绝入队。失败只计入固定原因，不持久化原始失败正文。原 Agent 文件保留，后续隔离界面通过受控本地引用重试。

本批文字策略不是通用秘密识别证明。任意无标签短密码、未知编码／格式和图片中的凭证仍需专门覆盖；多模态尚未实现，附件／内嵌媒体拒绝入队，不能按成功处理或静默丢弃。FR-07、FR-15 完整验收保持未完成。

## 持久性与状态

本地投递库与 Core 数据库分离，0600 文件、0700 目录、当前用户持有，拒绝符号／硬链接和未知 schema。初始化显式执行；普通打开不自动重建缺失库。库绑定 instance/device；切换中心或重新配对不能自动发送旧队列。

事务提交成功才返回 `queued`。重试读取不删除事件；接纳回执必须匹配 instance/device/event ID、已过滤正文摘要及服务端 receipt ID，事务保存后返回 `accepted`。相同回执重放幂等，冲突回执拒绝。`accepted` 仅表示服务器持久接纳，不表示记忆已生成或另一端已可用。重启、确认丢失、重复采集及并发入队不得丢失或覆盖原事件。

SQLite 不存未过滤正文、连接凭证或原始事件正文的摘要。出队再次执行当前过滤策略；存量内容若需重新过滤，停止投递并要求显式生成新修订，不能悄悄改动已存在的幂等事件。

后续传输必须先握手核对 instance、设备撤销、项目权限及删除水位，再发送；不得将本地持有的旧授权当作 NAS 授权。永久拒绝、离线重试、删除抑制和已处理状态随后接入，不以当前队列测试宣称 FR-06／FR-11 已完成。

## 验证与兼容性

使用合成凭证覆盖正文、键、嵌套元数据、工具结果和失败路径；检查 SQLite／journal 文件及 CLI 输出不包含合成原值。验证事务重复／冲突、并发插入、重启恢复、回执丢失重放、绑定不符、文件／schema 异常和当前过滤策略重检。上游脱敏及来源区间测试单独运行。

新队列 schema 1 不修改现有 NAS 身份库或 Core 数据库；本阶段不存在旧客户端升级。未来 schema 变更需显式迁移，不能删库或静默重建。此记录为开发者设计自审，尚非独立同行审查。
