# ADR-0010：Agent 每轮授权召回与缓存前置合同

日期：2026-10-25。状态：在线召回分步实现。关联 FR-01、FR-02、FR-03、FR-05、FR-06、FR-07、FR-11、ENG-01。

## 复用调查与差异

固定上游 `b7d9f0e` 的 Host Bridge `memmy-adapter/claude-code/event-adapter.ts` 已有 UserPromptSubmit 入口、不可信历史边界、限额和错误处理；runtime.ts 绑定本机 broker 发现和 host 凭证，receipt 固定 all-apps。其 recalledQueries 会使同会话已命中的相同查询不再检索，context_auto_recall.py 也会跳过普通消息。这与本项目“已开会话下一轮使用新记忆”的默认自动接续不一致，不能直接启用该触发策略或伪造本机 broker。

复用 Hub 已有 RemoteConnection、read_remote、ReadReply、凭证过滤和 SourceConfiguration，继续由上游 HyMemoryBridge／SDK 执行检索，不新建索引或召回引擎。新增通用的授权结果汇合／有限上下文呈现，以及薄的 Claude stdin/stdout hook 适配。上游 context 呈现函数不是公共导出，且字段／权限合同不同；Hub 根据自己的 ReadReply 保留 scope、记录 ID、原始引用和截断标志。没有复制 MemTensor 派生源码。

## 在线合同

`cloud-memory-connector claude-hook` 接收最多 64KiB 的原生 hook JSON。仅处理 UserPromptSubmit；不读取 transcript_path，不因 Stop 再写入一套消息。原生采集仍由已有 collect-watch 完成。source 文件绑定项目 UUID 和精确 workspace；payload.cwd 和 hook 进程实际 cwd 都必须匹配，失败不发查询，不从输入接受其他项目／凭证／URL。

每次调用重新读取私有连接和来源配置。默认读取绑定项目，显式 --include-global 同时选择 global，用于跨项目个人偏好；两者均须服务器授予 memory:read。每轮重新检索，包括相同问题，不以已有会话状态省略查询。只取记忆，原始历史须另行授权读取。

完整 prompt 先在本地过滤，再按查询合同限制到 4096 字符，并再次过滤／验证；超限截取明确标示。最多两个 scope、每个最多五条候选，输出最多五条、正文合计最多 6000 字符、完整上下文最多 24KiB；携带原始引用，正文或引用未完整呈现时标记截断。两 scope 结果须属于同一设备授权 revision，否则整批舍弃。任一配置范围读取失败时不输出成功范围的旧结果，也不扩大范围或换凭证重试。

读取总期限八秒，超时取消待发／在途客户端任务；服务器原有并发限制和 SDK 取消清理规则继续生效。历史内容通过 JSON 行呈现并转义所有边界字符，头尾说明它是参考数据，当前请求和更高优先级指令优先。该处理不是提示词注入完全防护的证明。

成功、空结果、拒绝、暂不可用分别呈现。空结果不宣称“没有记忆”；拒绝／超时不把缓存或旧输出当作当前已授权结果。hook 始终允许正常对话继续，stdout 只有宿主合同 JSON，stderr 只含固定状态／错误码，不记录查询、密码、会话路径或响应正文。已经返回给 Agent 的上下文不能撤回，原 Agent 的历史不自动修改。

## 离线缓存必须补齐的合同

用户确认的离线读取要求保持不变。本轮在线 hook 不创建缓存，也不把旧回复伪装成有效的离线记忆。现有 list/search 是实时分页，不是同步快照，不能据此安全维护完整副本。

后续缓存实现需要版本化的 scope 快照／增量合同、权威存储代际、授权 revision、治理水位和删除抑制记录；事务应用后才能标为当前。断网期间可明确使用最后一次已授权的本地缓存，重连先核对权限／治理状态，再恢复自动召回。撤销、忘记、删除、备份回滚、重导入和旧离线端重连必须有对应的失效／防复活测试。原始历史缓存和记忆缓存分别按授权管理，不由读取一次记忆推断获得历史权限。

## 兼容、安装与验证

不改变服务器协议、数据库或既有来源配置；增加 CLI 命令与显式 global 开关。没有自动安装到日常 Claude 配置，先由隔离 settings 调用；可撤销安装和多 hook 共存随后实现。

验证固定错误、查询先过滤、项目/global 隔离、两范围授权变化、超时取消、恶意边界字符串、截断及重复问题刷新。真机探针使用实际 Claude CLI、实际 Hub HTTP 和 SDK／本地 embedding，在同一会话轮间更新合成记忆，检查下一轮模型请求包含新版本；随后撤销权限，核验最新注入不含旧记忆。生成模型仍是本机替身，不能推定真实模型质量、两机 NAS 网络、自动提炼或一分钟目标达成。
