# ADR-0007：连接组件的有界传输与自动补传

日期：2026-10-23，验证更新：2026-10-24。状态：实现、本地真实 TCP／CLI、本地和 NAS 容器及空实例升级回滚验证完成。关联 FR-02、FR-03、FR-04、FR-06、FR-07、ENG-01。完整自动采集、召回、删除协调与实际 Agent 验收仍保留原要求。

## 复用证据

固定上游 `b7d9f0e` 的 `one_memory/http_client.py` 提供 HTTPX 客户端工厂，保留回环请求不经过环境代理的行为；直接调用异步工厂，关闭环境代理、重定向并设置超时。无需新网络库或守护进程。

`host-bridge/src/notification-transport.ts` 和 `broker-client.ts` 面向本机 runtime discovery／broker，使用本机 host grant 与 source-changed 通知，未实现 NAS v1 身份、事件摘要回执或持久离线投递。保留其本机职责，不伪造 discovery。新连接层只组合既有本地过滤／投递库和 NAS 接纳接口，不复制处理队列、模型执行或采集适配器。

## 配置和出站边界

连接配置为显式指定的 0600、当前用户拥有、非链接文件，含 schema_version=1、origin、instance_id、device_id 和设备 credential。origin 必须是精确 HTTPS origin；HTTP 只允许 localhost／回环地址，用于隔离测试。禁止路径、userinfo、query、fragment、控制字符和无效端口；不接受管理员凭证。文件不纳入 Git，不把凭证放在命令行参数或状态输出。

本地队列的 instance/device 必须与连接一致，普通打开不能换绑或重建。每次传输读取当前配置，先验证设备 session 的实例、设备、活动状态与协议能力，再逐事件查询当前来源授权。新增设备 GET 来源访问回执，确认来源归属、scope 和 events:write 后才发送正文。服务端接纳事务仍重新核对权限；网络途中已经发出的请求无法撤回，不能宣称预检消除了撤销与传输之间的所有竞态。

出队重新核对摘要和当前过滤规则，将本次连接凭证纳入已知秘密集合；需要再次过滤的旧事件保留并报固定原因，不改动幂等身份。所有请求只发向配置 origin，禁止跟随重定向；每个请求有完整时间上限和响应字节上限，拒绝非 JSON、重复键、错误协议和不匹配回执。不保留 HTTP 异常 cause／正文／URL 或 headers。

## 发送与恢复

CLI 增加单次 `send` 和持续 `watch`。持续模式显式启动，不安装 LaunchAgent、不修改 Agent 设置。队列按顺序发送；只有 HTTP 202 且 instance/device/event/digest/receipt 均匹配才确认 accepted。中断或丢失回执保留 queued，后续完全相同的事件重放由 NAS 持久队列去重。

连接失败、超时、408／425／429 和 5xx 使用有上限的指数退避自动重试；正常轮询以秒为间隔。401／403、协议不匹配、实例变化、冲突、正文拒绝或私有文件异常停止传输，保留记录并输出固定错误码，避免无意义重复发送或静默丢弃。当前失败事件会停止本次发送序列；跨事件冲突管理界面随后实现。输出仅含计数和固定状态，不打印正文或凭证。

`accepted` 不等于 processed／recallable。未激活模型时任务可持续 pending。完整生产启用前必须接入删除抑制状态协调，再发送旧队列；本阶段仅用合成数据验证网络传输，不把缺少治理水位的握手声明为完整同步协议。

## 兼容性与验证

本地投递 schema 不变；原 init／enqueue／status 命令继续可用。连接配置独立版本，未知格式拒绝。NAS 新增只读来源访问接口和 capability；发送器连接不具备该能力的旧 NAS 时停止，不回退到未预检的上传。

开发者设计自审覆盖：配置私密性、TLS／origin、当前授权、回执匹配、超时／大小限制、取消／断网恢复，以及拒绝路径不泄密。测试需包含真实 TCP Hub、前后断线与响应丢失、NAS／设备／项目误配、重定向零跟随、超大／慢响应、来源撤销后无正文出站、重启补传和已安装 CLI。上游 HTTP 工厂原测试保留运行；真实跨设备时效和 Agent 自动行为另行验收。本记录不是独立同行审查。
