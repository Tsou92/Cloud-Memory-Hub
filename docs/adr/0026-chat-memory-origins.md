# ADR-0026：普通记忆语义版本的生产来源

日期：2026-11-02。状态：原生版本标记已实现，Hub 来源接线待完成。关联 FR-08、FR-09、FR-10、FR-11。

## 数据流与复用

ADR-0025 已冻结实际合并候选，但原生 UPDATE 保留的 custom.request_id 不是当前版本生产者。复用固定上游的 record_origin 摘要与校验、MemoryNode 序列化、三种存储共用 payload 转换，以及 writer 原有 ADD／UPDATE／SUPERSEDE／直接写入。不得按正文匹配生产请求，也不改变模型提示和候选选择。

```text
已知写入请求 -> 原生合并/直接写入 -> 为实际完整语义状态生成来源摘要
                                     |
                                     v
                               原生 payload 持久化
                                     |
                                     v
下一轮最终候选 -> 不可变快照 -> 校验版本摘要 -> 后续核验生产原文/产出关系
未标记的语义更新 -> 清空旧来源标记 ----------------> 未证明，不猜测补齐
```

## 格式与兼容

MemoryNode 与通用 payload 增加可选 origin_request_id、origin_digest，旧字段缺失表示未证明。普通记忆使用独立摘要域；既有 experience/fact 摘要字节保持不变。摘要覆盖节点、用户、Agent、会话、来源、层级、owner、正文、标签、记忆/创建时间，以及实际合并提示会使用的 topic_paths、event_facet、topic_assignments。向量、访问计数、演化状态和未进入模型的辅助元数据不属于此语义摘要。

原地 UPDATE 复用 writer 已取回的旧节点，与实际 updates 合并后生成标记，不增加读取。旧节点取回失败、非法元数据或请求标识不可用时清空标记，保持原写入行为；不把捕获失败标成已证明。单条和批量 ADD、SUPERSEDE、直接写入在持久化前标记完整节点。后台画像、摘要、意图与其他未接线写入不冒用当前请求。

Chroma、FAISS、Qdrant 的 payload 更新入口共用失效规则：修改语义字段却未显式携带完整来源对时，清空旧来源；访问计数、向量或演化状态等辅助更新不更换生产者。custom 更新保守失效，因为无需额外读取就无法判断其中结构字段是否变化。全量新节点默认无标记；携带旧标记却改动语义内容的节点不能通过摘要校验。

这些标记是受控 SDK 写入的一致性证据，不是密码学签名。后续 Hub 必须同时核验真实原文、唯一生产请求、作用域、产出索引、时序与阶段关系，不能只信标记。公共事件入口不接收这些内部字段作为来源声明。

旧镜像读取新 payload 不需要迁移；旧写入方对新数据的修改不能算作已覆盖的来源链路。旧数据不回填生产者。安装与兼容性实测另记。

## 检查与失败场景

顺序审查架构、数据路径、代码复用、测试和性能；不称作独立同行审查。覆盖序列化、三个后端的持久化/重开、未标记更新失效、非语义更新保留、非法/不完整标记、实际 writer 的所有写入分支、读取失败、旧数据以及 UPDATE 前后快照。保留现有上游回归，运行 make check 和相关 Hub 测试；明确区分合成模型、真实存储和 NAS 安装证据。

额外成本为固定语义字段的序列化和摘要，没有新模型调用、数据库或额外逐节点读取。Hub 普通合并输入的来源接线、其他模型阶段、删除执行和恢复防复活仍须继续完成，不能由本 ADR 单独开启删除。
