# ADR-0027：普通记忆合并阶段的来源关系

日期：2026-11-02。状态：实现中。关联 FR-08、FR-09、FR-10、FR-11、FR-12。

## 复用与数据流

固定上游 b7d9f0e 加补丁 0013/0014 已提供实际候选快照和语义版本来源，但没有 Hub 接纳原文、项目授权或产出回执索引。复用这些证据、record_origin.verified_origin、MemoryNode 反序列化及已有 ReconcileGraph / ChatGraph；不重写模型、检索或记忆存储。

```text
SDK 持久写入结果 -> 校验后的合并快照 -> 与原文产出关联在同一事务归档
冻结候选的版本 -> 唯一生产请求 -> 已验证原文/作用域/类型产出
                                     -> 生产时历史输入与合并阶段
实际 used 阶段 -> 当前语义产出；不把可变记忆 ID 当作旧版本父节点
```

新增 cmh_memory_inputs_schema / cmh_event_memory_inputs 版本 1，保存 scene/capture、规范 JSON 与摘要；与现有归档分开，旧程序可忽略新表。抽取现有聊天归档的有界、不可变 SQL 保存逻辑供两类归档复用，保留旧表、字段、错误码和 schema。结果缺字段保存 capture=null，表示未观测；不从当前记忆猜补旧输入。缺档由原持久结果补核对，不能重新写入 SDK。

新 cmhm: 阶段 ID 为内部保留前缀，普通 SDK 产出不得冒用。只有 used 阶段连接语义产出；skipped、fallback 的候选证据仍可供范围观察，但不伪造成功模型派生。not_used 不生成模型阶段。unavailable、摘要错误、未知生产请求、跨域、非对应产出、自引用、循环和超限拒绝提供完整范围。

生产者身份核验用户、Agent 与来源。UPDATE 保留原会话标识，因此不把候选的 session_id 当作最新生产请求会话；版本摘要仍绑定该字段。候选生产请求连接其当时的合并阶段及聊天历史，而不是当前库存版本，避免原地 UPDATE 自环和引用未来的当前版本。

## 四项工程评审

- 架构：归档和产出关系同事务提交，失败回滚；沿用完成/未知任务恢复和作用域校验。SDK 捕获先于模型写入是因果证据，接纳顺序或业务时间不是执行时序，不额外假定两者相同。缺失画像/后台阶段、独立执行时序证据与删除执行继续补齐，本次不开放删除。
- 代码：复用归档 SQL、生产回执缓存和图预算；两种候选类型使用各自验证器，保持已有 productivity 格式兼容。新增记录不会被当作客户端可声明的来源。
- 测试：真实 SDK 三轮跨会话原地更新、重开/回执清理、授权读取、范围方向；篡改、旧数据、补档、事务失败、重放不重写、未知原文、跨域、自引用/循环、预算和 reserved ID 均需覆盖。模型采用合成响应，安装/NAS 验证另记，不替代模型质量或六入口验收。
- 性能：共享回执和生产者缓存；先用 SQL 长度限制档案读取，再解析规范 JSON。所有归档、阶段、父边和内容计入既有总预算；不增加模型调用，也不逐候选查询当前 SDK 节点。

此为顺序自审，非独立同行审查。原生数据格式不变，无新模型配置；本轮新增的仅为 Hub 内部归档与关系。升级前备份；新旧镜像读取兼容不等于生产降级或备份恢复已获验证。
