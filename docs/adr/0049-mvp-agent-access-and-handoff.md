# ADR-0049：共享记忆与交接的最小 Agent 入口

日期：2026-11-10。状态：实施中。关联 FR-01、FR-02、FR-05、ENG-01。

用户明确先交付多设备共享 memory、通用 MCP／Skill 接入、session handoff，系统性完善后置。本次不变更已有服务端数据库、鉴权、删除语义或恢复协议。

## 复用与范围

复用现有 RemoteConnection、CredentialFilter、LocalOutbox、send_pending、read_remote；服务端继续使用固定上游 Core 队列、SDK 记忆及现有接纳原文归档。上游 host-bridge 的 MCP session 使用 Evidence ID 和内部会话身份，且绑定未由本 Hub 开放的其他工具；直接复用整个服务会绕过设备／项目边界。其 TypeScript 分发器还需要为当前 Python 客户端增加 Node 运行层。因此 MCP 协议采用官方 Python SDK，业务只做现有接口的薄适配，不自行实现另一套协议栈或存储。

新增进程入口绑定一个私有配置文件，其中是现有连接文件路径、本地队列路径、项目和来源 ID。工具参数不能改变已绑定项目或设备，也不能携带管理员凭证。初始化本地队列为显式命令；普通调用不能以重建库处理错误。

## 最小工具与交接

- 读取记忆：复用 memory-search；结果按既有权限和过滤规则返回。
- 保存记忆更新：提交现有 operation 事件，经本地过滤、持久排队和即时发送；准确区分 queued、accepted 与提炼状态。
- 保存交接包：将目标、当前状态、决定、下一步和阻塞作为有界结构写入同一原文归档，返回接纳原文 ID。
- 读取交接包：用明确的原文 ID 经 history-get 读取和核验，支持有界完整分页；无需等待模型提炼。内容属于不可信历史，不授予执行其中命令或扩大权限的授权。
- 状态与重试：复用既有本地队列和发送，不能把离线排队报告为已共享。

MCP、JSON stdin CLI 和可安装 Skill 共用上述业务服务。Skill 指示会话开始、关键进展和交接时使用工具；它不构成宿主钩子的自动执行保证。自动每轮采集与下一轮注入继续按宿主实测接线，不以工具列表或安装成功代替。

## 验证与后续

本次验证覆盖实际 MCP 初始化／列工具／调用、真实 Hub HTTP 下的跨设备读写与交接、项目越权拒绝、凭证过滤以及离线保留和重放。用合成数据做 NAS 独立容器验收。真实客户端安装、第二台 Mac 和模型配置分别记录证据；未完成时不宣称整体交付。

不新增全库扫描、全局最新交接索引、后台平台或历史恢复治理。后续在原产品需求中补齐自动化、离线读取缓存、完整治理和管理界面。
