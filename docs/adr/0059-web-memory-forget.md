# ADR-0059：网页普通记忆忘记入口

日期：2026-11-10。状态：网页实现与隔离回归完成，待 NAS 安装验收。关联 FR-10、FR-11、FR-12；发布门槛 R1-04。

## 复用与范围

复用 ADR-0032／0036 的管理员 `governance/preview`、`governance/execute`、持久操作身份与独占重验，以及固定上游 SDK 记忆详情和 Hub 项目读取组件。网页只补交互，不新增存储、权限、治理协议或删除语义。

现有预览是观察结果，`execution_available: false` 不代表完整执行可保证。网页只允许对已浏览完整影响范围、来源无缺失且不包含已知不支持生产力类型的普通记忆申请忘记；确认前明确提示执行时仍会重验并可能拒绝。是否实际完成以执行器的匹配回执为准，不由前端推断。

当前预览不能证明全部副本可清理，因此网页不提供彻底删除执行。保留上游 DELETE 的服务端保护，不隐藏限制或把拒绝记为成功；旧日志、生产力内部输入和全域物理治理均不纳入本步。

## 行为与兼容

- 从当前项目记忆详情打开影响预览。分页携带同一 `view_digest`，完整浏览后才能确认；范围变化必须重新预览。
- 展示记忆与原文数量、短正文、关联原因和效果。忘记停止自动调用及再次自动提炼，原文仍可按 ID 主动查阅；已发送给其他 Agent 的内容无法撤回。
- 确认前在当前站点会话存储保留实例、项目、记录 ID、摘要、操作 ID 和影响数量，不保存正文、凭证或模型响应。存储不可用则不发执行请求。
- 请求失败、取消或响应不匹配均保留原请求；恢复按钮复用同一操作 ID、选择和摘要，不自动重建请求或伪装成功。明确 `governance_preview_changed` 时才允许用户重新预览并再次确认。
- `completed` 且实例页面所绑定的项目、动作、操作 ID、影响数量全部匹配后刷新记忆列表和问答。切换项目／离开视图取消旧请求，不把迟到结果写入其他项目。
- 会话存储仅用于本浏览器恢复请求，不是治理权威或备份；服务端继续承担鉴权、来源证明和幂等核对。

## 验证

组件与传输测试覆盖完整分页、范围变化、已知不支持类型、确认后刷新、断线后的同请求重放、响应错配、跨项目取消。保留原非 Hub SDK 详情测试。这里的 HTTP 替身验证网页合同；实际 NAS 忘记与列表／问答结果由安装验收另行记录。


2026-11-10 本地验证：7 个网页测试文件共 46 项通过，无跳过；其中新增忘记交互 9 项，Hub 控制台新增 2 项列表／原文刷新回归。TypeScript、Hub 模式生产构建、7 文件 Biome、`make check` 均通过。固定上游加 27 个既有补丁的基线可顺序应用 `0030-hub-console-governance.patch`，工作树反向应用检查通过。构建使用本机 Node 22，出现上游要求 Node 24 的提示；正式容器仍使用既定 Node 24 门禁。

独立源码审查发现从首页／原文页恢复未知操作后旧内容没有刷新，已给两个视图增加成功后的重新挂载，并以原文页恢复完成的组件回归验证。这里未操作浏览器或访问 NAS；不能将组件测试记为真实网页／模型或日常内容治理通过。
