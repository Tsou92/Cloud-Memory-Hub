# ADR-0069：自动会话接续

日期：2026-11-11。关联 FR-01、FR-02、FR-03、FR-04、FR-05、FR-07、FR-08、FR-12。

用户接入项目后，无需逐轮调用保存记忆或手动交接。复用项目范围的 `UserPromptSubmit` 与 `Stop` 捕获、稳定事件身份、本机私有队列、已有 NAS 接纳和模型整理。Claude 使用 `prompt_id`；Codex 使用原生 `turn_id`。支持范围以实际宿主验证为准。Codex 对新配置的非托管 hook 有一次性信任流程，详见 [OpenAI Docs](https://learn.chatgpt.com/docs/hooks)。安装器不替用户批准信任，不写入其他项目或系统级代理。

接纳的已过滤原文就是会话权威来源。按项目、来源和会话聚合，只使用当前有效的记录修订。接续摘要从最近可见目标和进展生成有界摘录，独立于长期记忆生成结果；同一项目的相关候选先进入下一轮上下文。完整 Markdown 按需读取，用稳定的原文锚点和游标逐页拼接已采集正文。首轮适配范围是用户可见提示及最终可见回答，不声称复制原生会话、未采集工具内容或整个本机旧历史。

沿用 `history:read` 的项目授权、授权版本复验、维护准入、凭证过滤和忘记／彻底删除规则。聚合和自动召回不使用单条原文追溯的忘记例外。摘要明确标记为参考数据，正文中指令不取得任何权限。读取过程不新建任务或原文副本，也不额外调用付费模型；NAS 仍以既有模型队列自动提炼长期记忆。

新增 `session_briefs`、`session_markdown` 两个只读工具，保留既有显式交接合同。旧连接文件默认直连；新自动组件使用配对验证的路由，只有 HTTPS 允许环境代理，HTTP 回环保持直连。无数据库迁移或新增用户开关。兼容旧 Hub 的自动召回可继续读取近期原文。
