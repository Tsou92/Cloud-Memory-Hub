# ADR-0071：首次登录时设置管理员密码

关联 FR-07、FR-12、ENG-01。首次初始化保留 NAS 内的随机管理员凭证作为安装器调用 API 的身份。新格式标记待设置状态，旧格式仍按既有登录方式工作。固定词 `admin` 只能与安装实例派生的一次性证明一起在首次设置页使用，不能通过普通登录或 API 获取管理员权限。

复用 Hub 的 Origin 和登录限速检查、现有管理员原子换密和上游 `UISessionStore`。首次设置页面从 URL fragment 读取并清除证明，提交时同时校验确认密码。在新凭证写入成功之后才签发后台会话。更改成功后，旧凭证和由它派生的首次设置证明失效，重启继续使用新凭证。管理员凭证仍使用原私有文件，无新数据库或备份格式；旧实例升级不进入待设置状态。

电脑上的首装入口通过受控 SSH 从对应容器取一次性证明，在本机打开页面。证明不打印到终端或 Agent 日志。已安装的旧版可显式运行 `--open-admin`，在 Mac 打开登录页并把凭证放到剪贴板。此操作沿用管理员已有的 NAS Docker 权限。
