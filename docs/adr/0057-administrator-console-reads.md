# ADR-0057：管理员网页读取真实 Hub 项目

日期：2026-11-10。状态：管理员读取实现与本地相关回归通过，待问答／网页组合及安装验收。关联 FR-01、FR-03、FR-10、FR-12、ENG-01；发布门槛 R1-02、R1-05。

## 复用与缺口

固定上游 `b7d9f0e0f417eae30b192882f848b432484c20a6` 的网页与 Core 原生库面向安装实例自身；Hub 的远程项目位于 `cmh:<instance>:<scope>`，不能把网页继续读取 `local` 得到的空列表视为真实项目状态。

继续复用 `CloudBoundary` 的管理员 Bearer／浏览器会话及同源保护、`remote_api.require_admin/read_body/response`、既有项目／来源数据库，以及 `RemoteRead` 和 `UnifiedReadBridge` 的权威 hydration、作用域核验、抑制、来源关系、隐私过滤和分页预算。不创建第二套记忆存储，也不临时注册设备或伪造设备凭据。上游原生读接口没有 Hub 项目身份与独立治理表，故增加薄的管理员控制台接口。

## 鉴权与共享查询

管理员入口只信任 `CloudBoundary` 写入的 ASGI `cmh_admin` 状态。设备凭据不能调用；浏览器 POST 仍要求精确同 Origin。所有查询必须显式指定已存在的项目或 `global`，没有默认 `local`、全项目合并或未知项目空结果。

从既有 `RemoteRead` 提取不带设备身份的有界查询结果，管理员和设备共用查询、同一个并发预算、错误映射及正文／元数据保护。设备 `ReadReply`、permission 前后重核和 revision 变化拒绝保持原合同；管理员使用独立响应，不出现虚构 device_id/revision。控制台隐私过滤包含管理员凭证、加密主密钥及本次浏览器会话值；不向前端返回这些值。

列表、搜索和按 ID 读取继续核对目标项目及当前有效状态。ADR-0056 的 forgotten 列表过滤与显式 history-get 保留规则不变，purged 在所有读取中继续隐藏。响应 `content_trust=untrusted_history`，正文只作为历史数据，不作为权限或指令。

## 控制台合同

具体 DTO 见[管理员网页接口](../console-api.md)。本步提供：

- 管理员 bootstrap：真实实例 ID、包版本、Hub 产品标识及有界分页项目；`global` 单列，前端必须主动选择。没有可证明的构建提交时返回 `build_revision=null`，不推断版本或部署来源。
- 所选项目摘要：项目身份、该项目分页来源及设备名称／撤销状态。来源 active 不等于设备在线。来源计数来自同一项目的权威来源表。
- memory-list/search/get、history-list/get：复用现有请求模型和读取项，返回本次 `returned_count`、`next_offset` 与检索预算标识。

不把 SDK 候选 total 当成可见记忆总数，也不为摘要无限扫描。首批摘要的可见记忆／历史总数明确为 null、`count_state=not_computed`；前端显示实际已加载数。存储／查询失败返回固定错误，不能改成成功的空数据。分页过滤后可以为空，next_offset 非空时继续读取。

## 兼容与范围

仅增加管理员路由和内部共享查询，不更改设备协议版本、数据库、来源注册、配对或治理执行。旧客户端继续原样工作。旧服务端不提供控制台端点，应显示不支持／连接失败，不能静默切回 `local`。构建、页面接线、问答模型和真实 NAS 网页验收另行集成，不由本步 API 测试推定通过。

## 验收

真实临时 Hub／SDK 验证两个项目、显式 global、Agent 接纳原文、当前记忆、分页、来源与精确 get；管理员与设备读取内容一致。覆盖无管理员／伪造状态头／设备凭据拒绝、会话同源、未知项目、跨项目 ID、旧版本 hydration、forgotten/purged、凭证过滤、固定错误、响应预算和 shared read 槽位。保留既有设备撤销／revision 与读取回归，不进行真实历史导入或外部模型调用。

本地读取专项 7 项通过；与既有设备、原文、生产力读取、hook、治理及认证相关的 12 个测试文件合计 167 项通过，无跳过。合成模型替身与隔离数据只验证后端调用链；最初的新上游副本缺少内置 embedding 资产，补齐并按固定摘要核对后重跑通过。对应测试与边界见 [Hub 测试索引](../../apps/hub/tests/TEST_INDEX.md)，不包含后续问答或浏览器验收。
