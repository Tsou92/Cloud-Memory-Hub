# ADR-0061：产品开源许可

状态：接受；关联 ENG-01、发布门槛 R3-04。

用户已授权以 GitHub 自行部署产品完成发布。Cloud Memory Hub 自有源码采用 Apache-2.0，与固定上游 Hy-Memory 的许可一致，便于保留复用关系、修改声明及公开分发。采用 Apache Software Foundation 提供的[完整许可证文本](https://www.apache.org/licenses/LICENSE-2.0.txt)，仓库与产品 wheel 携带 LICENSE 和 NOTICE。

这项选择只覆盖项目自有内容，不改写腾讯上游声明，不把第三方依赖或模型资源的许可证统一替换。发行包继续携带上游原许可、固定提交、补丁清单及依赖来源／许可信息。参赛包沿用产品许可，不因赛事格式改变项目主体。

许可证文件存在不等于已公开发行。远程仓库、版本制品、完整来源校验及实际新机验收仍按发布计划执行。
