# ADR-0029：Hub 基础画像来源接线

日期：2026-11-03。状态：已实现，安装与 NAS 验证中。关联 FR-08、FR-09、FR-10、FR-11、FR-12。

## 复用与兼容性

复用补丁 0015 的 basic_profile_inputs、原生 MemoryNode 和 profile 摘要、既有 EvidenceArchive、ReconcileGraph 回执缓存/预算/作用域核验、ChatGraph 历史输入，以及 SDK 原生读取。Hub user_id 已编码实例和作用域；画像的空 agent_id/session_id 表示此作用域内用户级共享，不赋予跨项目权限。全局偏好仍使用已授权的 global 作用域。

已有 cmh_event_output_links 摘要不可改写，且普通 memory_ids 不包括画像。增加独立 schema 1 画像归档与画像产出索引，保持旧产出表/摘要和队列回执合同。索引只收录持久结果确认的 output_ids，并通过原生当前节点验证 ID、L0 层、用户级身份、默认 source 以及生产请求摘要；attempted IDs 留在归档中，不伪装为已确认产出。缺失旧字段保持 null，不推断或重写原生记忆。

画像归档与索引同现有原文/产出/上下文事务提交，重放必须字节一致；缺档从已完成 SDK 回执补录，不调用 writer。索引具有单一产出生产者约束。旧版本忽略新表的只读兼容需要安装验证，不视为生产回滚。

## 来源关系与失败处理

新增内部 cmhb:receipt 输入节点，保存实际画像规则输入。画像产出连接对应原文、画像规则节点和提炼时聊天历史；不连接在画像更新之后发生的普通记忆 reconcile 阶段。旧画像候选通过独立 profile 摘要、唯一生产请求、作用域、对应画像产出索引和生产阶段证明来源，不以可变节点 ID 代替当时证据。

范围观察包含无变化的规则输入及部分副作用归档。unavailable、effects_complete=false、来源缺失/自引用/循环、索引不一致、未观测的 L0、错用户/层/身份、超预算均拒绝给出完整治理范围。旧链头状态是实际规则控制输入，尚不将当前连接当作独立执行时序证明或完整删除能力；删除执行继续关闭。

画像读取和范围观察同时核验当前原生 payload 的来源标记，防止曾经证明过的索引被沿用到后来未记录的修改。读取还比对待返回正文/用户/层与当前节点。范围扫描复用已有原生 payload，不新增逐条查询；画像产出登记与按 ID 读取最多增加一次原生读取。结构化规则输入的旧 KV 和链头复用上游纯函数重算核对，不另写合并算法。

## 验证与自审计划

- 架构：独立旁路索引保留旧摘要；不改变普通记忆生产关系或扩大用户作用域。
- 代码：抽取 MemoryNode 证据的共有结构核验，复用原生画像规则解析和来源摘要，避免复制更新算法。
- 兼容缺口修复：共享图遍历，并让含实际提示/规则内容的快照连接本次提炼的聊天历史。只给语义产出加历史父边会遗漏快照中的派生内容；普通记忆合并快照同样补齐该边，skipped 空阶段保持原行为。
- 测试：实际 SDK 仅画像的连续写入/无变化、跨 Agent 同作用域、原文读取权限、旧回执补档且禁止 writer、事务故障、不可变索引、来源/格式/预算异常、部分失败及新旧版兼容。
- 性能：每次最多一个画像产出核验，图共享回执缓存与总体预算；SQL 在读取正文前统计新归档字节，内部命名空间拒绝外部伪造。

以上为顺序工程自审，不是独立同行审查。后台派生任务、执行时序、删除/恢复、两机六入口与正式发布仍需各自验收。
