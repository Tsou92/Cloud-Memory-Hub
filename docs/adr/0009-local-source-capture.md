# ADR-0009：显式来源授权与本地持续采集

日期：2026-10-24。状态：分步实现。关联 FR-02、FR-03、FR-06、FR-07、FR-08、ENG-01。

## 复用与范围

固定上游 `b7d9f0e` 的 `imports/sources/claude_code.py`、`sources/common.py`、`access.py`、`readers.py` 已提供原生消息解析、工具记录、宿主包装排除、受控文件读取、增量游标及尾部改写检测。直接调用这些实现，保留其原有解析／访问／读取测试；先前的[真实 CLI 探针](../reviews/2026-10-24-claude-native.md)已验证当前入口。

上游 Host Bridge / memmy adapter 的安装及召回协议绑定本机 Core 发现、授权和 broker；不能冒充本机 broker 来连接 NAS。Hub 增加的代码仅将受控来源映射到现有远程事件和本地投递队列，不新增记忆引擎、解析器或 NAS 处理队列。

第一批只实现显式选择的 Claude 原生文字／工具记录采集。通用服务器继续接受独立 adapter ID；本地适配器按工厂注册，增加其他入口无需改变核心协议。自动读取 hook、安装器、离线召回缓存、跨设备去重、治理传播和多模态仍需后续实现，不能由本阶段代替完整验收。

## 授权与隐私边界

私有来源配置 v1 指定 adapter、source UUID、scope UUID、授权根目录、精确的原生 workspace 字符串和可选来源版本。`capture-init` 显式登记，不扫描；`collect` 执行一个有界批次；`collect-watch` 持续补扫，均不自动查找用户目录或修改 Agent 配置。网络发送继续使用已有 send/watch，采集不依赖 NAS 在线。初次采集从授权目录历史起点开始，未接入日常环境前仅使用合成数据。

来源只绑定项目 scope，不将项目历史自动归入 global。复用上游 `opaque_workspace_id` 比较精确 workspace；缺失或不同 workspace 的记录不入队，计入跳过数量。根目录身份与配置摘要在初始化时固定；重启后替换目录、修改 source/project/root/workspace 拒绝继续，不能隐式扩大授权。配置版本变化需显式迁移。

上游原生消息 ID／幂等身份在内存使用，本地索引保存带私有密钥的 HMAC，不保存基于原始正文的裸摘要。记录正文、原生会话／消息来源元数据必须统一过滤后才入库。游标的原始行校验摘要用于检测文件改写，不是共享内容；整个游标用已有 cryptography/Fernet 依赖加密，绑定 source/file 身份后保存。独立 0600 `capture-key` 位于本地 0700 状态目录，不上传，丢失／篡改时停止采集而非重建状态。

媒体块、解析失败、无法安全过滤和超限记录停止当前采集，不越过失败位置。已成功提交的前缀可保留；原生文件仍是失败记录的来源，诊断仅含固定错误码和计数。上游合法的非对话记录跳过并按固定原因计数，不能把跳过总数当作成功采集。

## 持久性、并发与兼容

在 LocalOutbox schema 1 增加独立版本为 1 的 capture 扩展表：来源绑定、加密游标、原生身份到 record/conversation UUID 的映射、过滤后内容摘要与修订。已有 events、binding、rejected 表不变，PRAGMA user_version 不变。旧版本发送器仍可发送既有事件；旧版本不理解采集扩展，不负责采集。未知扩展版本拒绝打开。

事件入队、身份映射／修订及对应游标在同一个 `BEGIN IMMEDIATE` 事务提交。保留上游一条原生记录拆成多条时的前置游标，崩溃重放通过身份映射去重；相同过滤内容不新建事件，变更产生新的不可变 event UUID 和递增 revision，不修改旧事件。这里的 revision 表示来源记录变化，并非已经实现用户纠错优先或删除语义。

原生消息 ID 缺失时，上游纯正文身份会合并同一会话中重复说的相同句子。文件采集在该回退身份上附加上游 source_ordinal，再生成 HMAC，保留不同原生位置；不重新解析文本。相同文件完整重扫保持幂等，但无原生 ID 的文件移动／前部改写，以及跨设备来源去重仍需后续对账，不能宣称已经解决。

采集进程持有本地非阻塞文件锁，防止并行扫描提交旧游标；发送器不持该锁，可与采集并行。停止或崩溃释放锁。watch 每轮重新读取私有配置，变更须重新核验绑定。上游处理未写完的 JSONL 尾行，后续轮次再读取，不将当前 EOF 作为会话永久完成。

验证中发现上游不变文件门禁只检查 inode、size、mtime，未调用尾部锚点校验。Hub 复用 discovery 和 read_listed，在加密游标旁记录实际 st_ctime_ns；ctime 改变但长度不变时重扫文件，其他追加／截短继续复用锚点逻辑。上游 AuthorizedSourceFile.changed_ns 实际是 birth time，不能代作修改时间。此修复保留原生解析和文件授权，不修改上游源码；同长度／同 mtime 改写已有失败到通过的回归证据。删除和全文件周期对账仍未实现。

初始化先生成私有密钥，再事务创建扩展；中断留下的密钥可复用，但不得覆盖。缺少现有密钥、不同密钥或加密游标损坏均停止，不创建第二套身份。恢复必须一起恢复本地状态库和密钥；本阶段不提供自动删除／重置操作。迁移回滚保留扩展表和密钥，回退旧发送器不破坏待发送事件。
