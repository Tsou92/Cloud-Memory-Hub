# ADR-0051：MVP 当前问题与最近原文联合召回

日期：2026-11-10。状态：已实现并安装到两台 Mac，实际宿主联合读取与对端读回通过，真实模型提炼后的旧记忆命中待验收。关联 FR-01、FR-02、FR-03、FR-05、ENG-01；接续 [ADR-0050](0050-mvp-visible-turn-hooks.md)。

## 目的与复用

最近五条原文能传播新决定，但较早记忆离开这个窗口后不会按当前问题自动找回。UserPromptSubmit 在原有最近原文读取之外，调用已有 `memory-search`；不增加搜索引擎、记忆存储或模型提炼流程。

继续使用固定上游 `b7d9f0e` 的可见文字提取及 SDK 搜索，经既有 Hub 授权读取合同访问。复用 `recall.py` 的完整查询过滤、截断与上下文呈现，以及 `AgentAccess._read` 的凭证、项目、返回结构验证。原先独立召回与本轮 hook 共用查询准备函数，避免过滤规则分叉。

## 合同与兼容

- 上传当前轮之后，并行读取本项目的相关记忆与最近原文。先过滤完整问题，再截到 4096 字符；查询不进入诊断输出。
- 成功回执须属于相同的实例、设备、项目和设备权限版本，操作须与请求相符。任何非重试错误（含权限拒绝、撤销、无效回执）或版本不一致，都放弃本轮全部上下文，不用另一条成功读取掩盖拒绝。
- 仅一路临时失败且另一路成功时，输出明确的 `partial` 状态和固定的不完整提示。两路失败或整个网络期限耗尽时，不输出历史正文；不使用旧缓存。
- 相关记忆优先，与最近原文交错共享最多 5 条、6000 正文字符、24 KiB 的既有预算。原文分页、候选或正文截断仍显式提示；空结果不表示没有记忆。
- 保留包括投递在内的 8 秒网络总期限、Stop 静默行为、稳定事件身份、持久队列及显式工作目录绑定。旧 MCP/CLI、服务器协议、配置和数据库无迁移；回退客户端即可恢复仅最近原文的行为。

## 验收边界

相关测试须证明旧决定不在最近五条仍被当前问题召回、双路并发、共同预算、完整问题先过滤、不同权限版本整批拒绝、单路临时失败的明确降级及两路失败无正文。保留原有采集、回放、离线与真实 HTTP 授权回归。

本次合成回执和本地 HTTP 测试只验证客户端合同，不证明 NAS 已完成模型提炼；真实模型提炼后跨机搜索和 Claude 采纳须另行验收。
