# ADR-0025：普通聊天合并输入证据

日期：2026-10-31。状态：原生捕获已实现，后续版本来源接线见 [ADR-0027](0027-chat-reconcile-lineage.md)。关联 FR-08、FR-09、FR-10、FR-11。

## 实际数据流与复用

ADR-0024 已覆盖提炼历史窗口。继续检查固定上游 `b7d9f0e`：extractor 的 `existing_tags` 和 `basic_profile_fields` 是保留参数，当前没有进入实际提示；用真实提示构造与合成 provider 验证中英文、配置组合，不为未使用的参数建立来源边。普通 `MemoryReconciler` 的候选正文、标签和结构字段实际进入模型；历史链先合并为链头、再去重，故不能捕获初始检索列表并当作模型输入。

复用原候选查询、链头选择、去重、提示组装、重试、ADD-all 回退，以及现有 `ReconcileInputCapture` 的调用内冻结和预算。在原提示调用前保存最终候选的不可变 payload 与实际提示；不保存 embedding，不修改模型提示、选择规则或调用次数。

## 数据与兼容性

`ReconcileResult` 增加可选输入证据，经 writer 的调用内输出参数传到原 `WriteResponse`，普通 add 与 add_extracted 持久结果增加可选 `chat_reconcile_inputs`。字段缺失表示旧版未观测，不从当前库存猜测回填。schema 1 沿用阶段、状态、输入及 rendered 结构；新增 memory 类型快照不改变原 productivity 类型的格式。

无候选／无新记忆为明确 skipped；模型成功解析为 used；模型不可用或解析失败且 ADD-all 回退为 fallback。捕获／预算失败以及冻结之前的未知异常为 unavailable，不能标成空 complete。未运行合并的 lite／direct-store 路径明确 not_used。重试相同提示复用同次冻结对象，不使用全局“最近一次”状态。

冻结预算沿用 512 记录／512 阶段／2 MiB；失败不改变原正常写入或回退行为。已有测试、源码兼容、持久结果重放与新旧镜像读取均须保留。

上游将部分检索异常内部处理为空候选、从而跳过模型；这种路径的 skipped 只证明模型未调用，不能当作检索成功或候选发现完整。原检索错误处理保持不变。

## 后续来源接线与完整性

可变 MemoryNode ID 和正文快照本身不能证明是哪一轮生产。下一步需核验原生写入版本及生产来源，再接入 Hub 原文、阶段和语义产出关系；不把现有 raw 来源字段当作完整合并血统。基础画像更新、摘要与异步图仍单独核验；不因这一快照完成而开放选择性删除。完整产品和六入口两机验收目标保持不变。

原生 SDK 合成写入已复现：原地 UPDATE 后 custom.request_id 仍保留创建请求，尽管正文已经变化。因此后续不能直接信任这一现有标记，需将实际语义版本和生产结果关联并校验；字段缺失、旧版本及其他未覆盖写入路径保持未证明状态。

## 验证与自审

覆盖最终链头／去重后的实际输入、结构与标签、原对象修改、禁用／空输入、解析重试、回退、异常、预算和并发隔离；真实 SDK 验证持久化、重开及幂等重放。运行相关上游回归、Hub 全量与 `make check`；安装／NAS 证据另记。架构、测试与性能采用顺序自审，不等于独立同行审查。
