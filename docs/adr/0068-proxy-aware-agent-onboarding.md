# ADR-0068：有代理环境中的 Agent 接入

日期：2026-11-11。关联 FR-02、FR-03、FR-07、FR-12、ENG-01。

## 已确认的故障

原安装器 `Remote` 固定使用 `ProxyHandler({})` 完成配对与 MCP 检查，但实际写入的是 Claude、Codex 等宿主的原生 HTTP MCP 配置。宿主可能继承 `https_proxy` 或使用系统代理。真实 Mac 上已用同一设备身份证明：安装器直连可用，而宿主把私有 NAS 交给代理后 TLS 连接重置；精确域名绕过后原生 Claude MCP 连接成功。

不能把 Python 的直连握手当作宿主连接成功，也不能向 HTTP MCP 配置加入只对 stdio 有效的 `env` 字段来声称解决。继续保留现有通用 HTTP MCP，不新增代理服务、后台 App 或 stdio 协议实现。

## 网络选择与重试边界

安装器支持检测当前环境路径与直接路径。HTTPS 使用现有环境代理规则，并可在无凭证的 GET 检查阶段确认直接路径；确定可用策略后，配对、授权和 MCP 检查固定使用该策略。需要经过代理的环境同样必须可用，不能继续一律忽略代理。

如果只有直接路径可用、宿主环境路径失败，先返回 `network_action_required` 与安全恢复说明，不领取新身份、不写 MCP。`health_verified` 仅表示无凭证健康检查通过；此时 `remote_verified`、`host_connection_verified` 均为 false。用户修复规则后重跑原链接，已存在的配对进度和身份仍保留。

HTTP 仅允许回环地址，并始终直连，避免将本机邀请或 Bearer 明文送往外部代理。所有 HTTPS 保持证书验证。鉴权请求不跟随跳转，不因结果未知而换路径自动重放 POST。

第一条安装命令及后续组件下载也要适配代理：Hub 专用 GET 先尝试环境路径，不可用时只对同一 Hub URL 直接重试。外网 Python／uv 发行下载保留原网络策略与摘要校验。错误只含固定代码和安全引导，不输出原始代理 URL、异常、邀请或凭证。

## 使用体验与兼容性

保留默认 HTTP MCP 与原设备身份；安装进度继续可恢复。明确区分配置写入、选定网络路径检查、宿主待重载和实际连接状态。自动检查无法证明宿主继承正确环境时，必须明确提示，不能显示最终连接成功。

需要用户调整时，为本服务的精确主机给出 Clash／Mihomo、Shadowrocket 域名分流或直连白名单说明、终端 `NO_PROXY` 补充、完整退出与重启宿主、`/mcp` 与 `memory_status` 验证步骤。当前环境可用而直连不可用时，应保留代理，不能错误引导添加直连规则。完整操作见[代理与网络指南](../proxy-and-network.md)。

不全局关闭代理，不设置全局 `NO_PROXY=*`，不排除整个 Tailscale 域或所有私网。GUI 宿主与安装终端可能有不同环境，不能仅凭安装器握手声称已经验证 GUI。

安装器默认不修改系统代理或 shell 配置。自动诊断无法安全完成宿主修复时，提供当前服务的精确规则与完整验证步骤，由用户或其安装 Agent 按说明处理。显式网络选项也不代表宿主已继承该选路。

## 验收

覆盖无代理、可用代理、仅代理可用、坏代理但直连可用、两条路径均失败、回环直连、不跟随跨源跳转、HTTPS 证书校验、写请求未知结果不重放、进度恢复及安全错误。操作系统专有分支分别记录实际执行和跳过范围。真实用户记忆不作为测试样例。
