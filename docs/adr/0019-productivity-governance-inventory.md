# ADR-0019：工作记忆及原文纳入治理观察

日期：2026-10-28。状态：接受，实施中。关联 FR-02、FR-08、FR-09、FR-10、FR-11、FR-13；延续 ADR-0012、0016、0018。

## 已有能力与选择

固定 SDK 的 coding_memory_meta.source_fact_ids、working_fact.derived_experience_ids 表示同一方向的事实到经验关系，fact_link 表示旧事实的后继。复用两套 SQLite 及四个 Chroma 集合、SDK 记录解码、现有只读连接和方向性规划器；不新增存储引擎或持久 schema。普通图／向量观察继续保留所有状态。

把各变体的全部经验／事实加入现有 cmhp 类型命名空间；互链的任一端都可以提供明确边，不能要求两个异步更新总是同时成功。fact_link 按版本关系处理。解析引用使用严格 JSON，不按主题、时间或正文相似度猜测关联。来源指向不存在或其他项目的记录时，范围计算仍明确失败。

向量集合可能保留 SQLite 更新或删除失败后的旧正文，因此另外观察每一条索引副本，以 cmhv 类型 ID 表示、以逻辑记忆为父节点，避免只扫描 SQLite 而漏掉副本。trace 以 cmht 稳定类型 ID 表示，并在 request_id 与已接纳事件完全相同时连接原文；没有确切关系的轨迹不按文本合并。索引、轨迹 ID 当前仅供管理员观察，设备读取协议没有新增路由。

Hub 配置库在同一只读事务内扫描本项目原文、结果标记和完整关联集合；核验原文摘要、链接摘要、输出类型与项目归属，再接到 SDK 节点。整体删除了链接行也会由结果摘要发现。只读预览不补写缺失关系，不调用模型或初始化 coding writer。

```text
SDK 普通图／向量 + 两套经验／事实 + 四套索引 + trace
          + 本项目归档及核验后的完整结果关系
          -> 合并预算检查 -> 既有方向性范围规划 -> 管理员观察
```

## 失败路径和未完成部分

单库读事务不等于跨存储快照；继续返回 observational / execution_available=false。SDK 未记录精确请求关系的 hy_code_chain 仍有独立正文、版本和 diff：发现本项目链数据时明确拒绝预览，不能忽略它。后续须在实际写入处捕获链节点关系。抽取器读取的前几轮 trace 历史也不一定完整反映到现有显式来源字段，不能据此宣布完整模型依赖或删除执行已交付。

扫描和内容沿用 10,000 记录／100,000 边／32 MiB 预算；全部来源合并后再次检查，超限失败。无效 JSON、未知状态、缺失集合、损坏数据库、跨类型冲突和关系摘要不一致不能静默产生空范围。空数据库允许无集合；有内容的集合仍必须扫描。过滤和授权沿用既有管理员边界。

完整暂停、持久执行计划、删除、抑制与备份恢复仍是原目标的后续必需部分，本次不开放执行。沿用现有 Docker 构建和 Linux amd64 分发；无新增发行物。实施顺序为存储观察、原文合并、HTTP 接入和集成验证，模块相互依赖，顺序实现，不启动委派。

## 架构、质量、测试与性能自审

架构复用严格存储适配和现有规划器；单独的只读模块负责 productivity，原文关系仍归已有 OutputLineage 管理。质量重点为类型 ID、防止跨项目查正文、错误码不包含 SDK 数据和不吞掉损坏。性能使用限量批扫描，避免逐条 SDK 搜索或模型查询；现阶段不增加可能过期的缓存。

真实 SQLite／Chroma 合成测试覆盖两个变体、同 ID 的经验和事实、替代链、双向记录的同一事实来源、共享经验不吞并独立来源、原文与 trace、索引副本、损坏与缺失引用、链数据拒绝、分页失效和重启。既有普通治理预览、来源关联与 SDK 核对回归保留。实现者自审不替代独立同行审查，真实模型质量和跨设备客户端验收分别完成。
