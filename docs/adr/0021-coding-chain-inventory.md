# ADR-0021：编程链轮次与线程的治理观察

日期：2026-10-29。状态：接受，本文范围内的只读观察已实现并完成本地／NAS 安装验证；不包含治理执行。关联 FR-08、FR-09、FR-10、FR-11；延续 ADR-0019、0020。

## 范围与复用

固定 SDK `hy_memory/coding/chain_store.py` 已维护 thread、round 和 repo_symbol，不新增链库或另一套 diff 分析。ADR-0020 已在 SQLite 提交之后捕获实际 round IDs 并保存于原 SDK 结果，Hub 上下文表核对实际 owner 后长期保留这些 ID。本次复用这些证据、现有只读 SQLite 打开方式和方向性关系规划，解除“只要当前项目有链就拒绝观察”的临时限制。

实现只扩展存储观察及原文关系合并，不新增服务、API、模型调用或协议迁移；沿用现有安装镜像与本地／NAS 隔离验证。完整删除执行、普通聊天及 reconciler 的全部模型输入依赖仍在原总目标内，不能由本轮观察替代。

## 数据与方向

- `cmhc:r:<正整数>` 为实际 round 行，类型 raw，正文包括 said、patch、adds、thread_id、seq 和时间。每个 round 的原文父节点来自核验过的持久上下文；同一行被多次更新时保留所有已证明的输入。
- `cmhc:t:<正整数>` 为完整 thread 行，类型 raw，正文包括归属、文件／分支／符号／范围及 body。其父节点是该线程全部轮次，表示存储上的聚合包含关系，不声称 body 中的每个字符都来自某条用户消息。
- 原生 seq 的相邻轮次构成版本边，线性存储、复用原有版本闭包。选中一个原文后纳入受影响的线程容器，不反向吞并其他轮次独立的原始对话。
- 不按文件名、文本相似度或检索匹配推断 fact／experience 到链的语义关系；现有来源与实际历史输入关系继续单独生效。

```text
已接纳原文 -> 已证明的 round IDs -> 轮次 raw -> 聚合 thread raw
                                <-> 原生相邻版本
已接纳原文／实际历史输入 -------> 经验／事实 -> 索引副本
```

只读取当前 namespace 对应 owner 的正文；当前 Core 未传 workspace_id，支持的精确 owner 是 namespace 加 `|`。同 namespace 的其他 owner 后缀不自动归并。发现未知后缀、零轮次线程、不连续／重复 seq、n_rounds 不符、损坏字段、悬空轮次或缺失证明时，拒绝返回完整范围。全局孤儿检查只读 ID 是否存在，不读取其他项目正文。

repo_symbol 原表没有 owner，SDK 的 index_repo 也没有可证明的项目映射。当前 Hub 的事件路径没有调用 index_repo；发现任何这样的旧索引时继续明确拒绝观察，不能把全局内容分配给当前项目。已有 thread.body 作为其所属线程的原始存储内容完整列入；不因此授权扫描或复制用户代码仓库。

## 工程自审与失败路径

架构：复用现有独占 SDK 准入；扫描过程只读、不初始化 writer、不运行 SDK 自动迁移。配置关系仍在一个只读事务中合并。跨存储观察仍不是事务快照，不能作为删除执行授权。

质量：类型化 ID 与层级集中定义；真实表结构、JSON、数值和归属显式核验。新增原生类型前缀加入普通存储保留标识校验，拒绝伪装身份。没有已核验上下文时，链节点不能作为“无来源”的正常结果返回。

测试图（实施前均为待验证）：

```text
真实 SDK observe / add
  -> 新轮次／同轮合并／第二版本 -> 持久上下文 -> 只读链扫描
  -> 归属、结构、序号、JSON、预算核验失败 -> 固定错误，无部分预览
  -> 与全部原文合并 -> 版本／聚合方向 -> HTTP 管理员预览
                                  -> 队列回收／进程重开 -> 同一范围
外项目正文 -> SQL 过滤；未知全局索引／孤儿 -> 明确拒绝
缺失上下文／round／thread -> 拒绝；普通记忆及零链场景 -> 保持回归
```

性能：在 materialize 正文前计算作用域内记录数和字节数；按线程批量读取轮次，不逐行扫描全库。相邻版本为 O(n)，避免生成 O(n²) 全连接。链与现有存储最终共同接受记录、引用和总字节预算。

这是实现者顺序进行的架构、质量、测试和性能自审。继续按已授权目标实施，不启动多 Agent 或外部委派。测试、安装制品、NAS 升级和未覆盖来源见[验证记录](../reviews/2026-10-29-chain-inventory.md)。
