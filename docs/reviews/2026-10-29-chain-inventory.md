# 编程链治理观察验证

日期：2026-10-29。关联 FR-08、FR-09、FR-10、FR-11。

## 实现与复用

复用固定 SDK 的原生链 SQLite、现有 SDK 准入、上下文证明及方向性规划。新增只读观察完整轮次与线程正文；轮次按实际行 ID 关联原文，原生 seq 构成相邻版本边，线程按实际 thread_id 聚合。普通存储不得冒充 cmhc 类型。

不新增模型调用、队列、运行数据库或迁移；不通过文件名／检索相似度推测链与经验事实的联系。未知 owner、无归属 repo_symbol、孤儿、缺失索引、损坏 JSON／版本序号、缺失来源及捕获失败均拒绝生成完整预览。设计及测试路径见 [ADR-0021](../adr/0021-coding-chain-inventory.md)。

## 当前证据

新增 22 项集中测试通过：实际 HyCodeMem 写入、同轮合并、相邻版本、完整 thread.body 读取、其他项目损坏正文隔离、预算、结构及来源损坏拒绝。Hub 集成使用实际 SDK add／链写入／结果库／归档／HTTP，语义提炼替身返回零产出；验证队列回收及重开后，零语义产出仍有完整链来源。选中一轮原文包含受影响版本与聚合线程，不吞并其他轮次独立原文；选择整个线程才包含其全部来源。

原有 foreign-chain 测试夹具只有两列假表，已改成原生 SDK schema，继续证明其他项目正文不被读取。原有断言把一条 diff hunk 的两个 `@@` 分隔符各计一次，修正为按 hunk 起始行计数。失败轮次未计入通过结果。

独立进程源码探针通过实际 writer 配合合成决策，验证历史输入与链预览、重启和接口调用路径，并在删除上下文证明后确认预览明确拒绝。完整运行时回归 389 项、固定上游 store／writer／场景路由／预处理／链配置回归 137 项通过。`make check` 的格式、静态检查、19 项工程门禁、文档链接、路径与凭证扫描通过。集中测试修正了空正则匹配的测试警告，另行复查；安装制品和 NAS 证据在实际执行后补充。

## 兼容性与边界

本次不改变持久格式，旧版本可以继续读取相同数据；旧版本仍拒绝存在链的预览，不能宣称具备新版能力。cmhc 为新增保留的类型前缀，普通存储若存在同名冲突，明确拒绝预览或输出核对，不能静默改成链记录。现有常驻实例继续在升级前停服备份三个卷，安装及 NAS 合成测试通过后再切换。

这是实现者的架构、代码、测试和性能自审，未进行独立同行审查。作用域正文先检查数量与字节预算，版本关系按 O(n) 建立；另有一次仅涉及 ID 的全局孤儿检测。repo_symbol 缺少项目归属时仍明确拒绝，完整模型输入依赖、删除执行、真实外部模型及六客户端／两机时效仍未完成。预览保持 observational 和 execution_available=false。
