# 用户后台样式合并验收

日期：2026-11-11。关联 FR-12、ENG-01。

## 范围与复用

独立编辑副本的基线与当前 43 个补丁后的 `hub-console.css` 摘要一致；用户只修改该样式文件，187 行新增、6 行删除。沿用原控制台、表单、菜单、按钮与业务接口，以补丁 0044 合并，不引入新网页框架或复制后端。用户编辑目录保持原样。

保留用户对页面滚动、侧栏滚动、表单对齐、按钮禁用状态及设置页深色主题的调整。浏览器检查发现原生菜单样式和后置的裸按钮规则覆盖了菜单颜色，因此在 Hub 范围内提高菜单规则优先级，并将菜单选项排除在主按钮规则之外；其余用户设计保留。
