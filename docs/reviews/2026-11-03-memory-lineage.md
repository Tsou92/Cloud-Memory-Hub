## 实现与评审

复用原生 chat_reconcile_inputs、MemoryNode 与语义摘要，把冻结候选接到唯一生产请求、已核验的原文/作用域/产出，以及生产时的聊天历史和合并阶段。原地 UPDATE 保留创建会话，所以生产者身份不错误地要求 session_id 等于更新请求。阶段不用可变记忆 ID 作父节点。used 阶段连接语义产出，fallback/skipped 保留审计证据但不建立成功模型派生边。

内部新增 schema 1 归档与 cmhm: 保留标识；补档使用已完成 SDK 结果，和其他产出/上下文归档同事务保存。抽取原聊天归档 SQL 供两类证据复用，旧 schema/字段/错误码不变。预算在 SQL 读取前统计新归档字节，图复用已有回执/生产者缓存，以增量计数限制阶段内容及父边，不增加模型调用。

已顺序自审架构、数据流、代码复用、测试、权限、失败处理和性能，无独立同行审查。未知/不完整来源拒绝给出完整范围；删除执行仍为 false。画像、后台任务及独立执行时序证明等剩余输入不在本轮完成声明内。
