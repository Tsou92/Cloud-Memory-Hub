# 同会话自动召回、重连与遗忘重投验收

关联 FR-01、FR-02、FR-03、FR-06、FR-10、FR-11、ENG-01。继续使用 NAS `mvp-6801367` 与两机已安装的 `272038f` 客户端，不更改日常配置或导入历史。本轮补组合证据，不新增治理架构。

## 真实两机重连与下一轮

Mac mini 的真实 Claude Code 2.1.319 从日常项目配置加载 UserPromptSubmit／Stop hooks；关闭本次模型的 MCP、Skill 和内建工具。第一轮完成且两条可见消息已被 NAS 接纳后，才在 MacBook 生成全新的合成项目标记和两个随机事实，因此第一轮上下文不可能预置答案。

MacBook 使用既有设备身份及独立私有 outbox，依次在三个独立进程中执行：

1. 注入仅影响测试进程的连接失败，内容留在本地队列；真实 NAS 查询该事件返回 404。
2. 恢复真实 HTTPS 连接，在服务端返回 202 后故意丢弃回执；客户端仍保留未确认事件，NAS 已有对应接纳记录。
3. 再次打开持久队列补传，同一事件取得原回执；重复 remember 保持同一身份和回执。

随后真实模型完成提炼，搜索命中 `kind=memory`、两个事实及本次回执来源。从开始离线入队到提炼并搜索可用，本次样例耗时 11.351 秒。NAS 两个数据库的定向只读核对确认：仅一份接纳回执、一份写入任务，任务 completed、attempts 为 1，产出一个原文和一个记忆。此证据证明重复发送不重复建任务，不表示网络只请求一次，也不是普遍延迟承诺。

保持 Mini 的原 Claude 进程和原 session，在第二轮只给项目标记，不给答案或目标记忆 ID。实际安装 hook 的搜索返回目标长期记忆，其最终渲染上下文含有精确记录 ID 和全部事实；Claude 最终回答正确复述两个随机事实。两轮模型结果均 success，四条可见消息均被接纳，模型工具调用为零。项目配置、用户 settings 与 Codex 配置哈希未变。

用户原有全局 hooks 同时保留。本轮使用透明的进程内观察器记录安装实现的实际返回值，不替换返回值、不注入 hook 配置；没有记录模型请求线上的完整报文，也不宣称排除了其他全局 hook 的贡献。目标记录的 `kind=memory` 由实际搜索回执确认，不能把渲染字段中的 memory layer 当作记录类型。

## 首次探针误判及只读复核

首次探针在第二轮的附加文本摘要比较处报 `stop_final_answer_mismatch`，随后清理进程，退出码为 143；原失败报告保留，不能将这次进程写成正常退出。

只读复核确认真实回答为 99 字符，含两个空行；生产采集路径 `visible_message → _messages → _plain` 按既有规则移除空行后为 97 字符，其 SHA256 与 Stop 观察记录完全一致，随机事实均保留。探针误将未经处理的结果与已处理的采集文本作字节比较。实际搜索、渲染及下一轮回答证据通过；独立复核报告与原失败报告分别留存，未为获得绿色结果再次调用模型。私有探针随后修正比较依据并做静态校验。

## 隔离与遗忘内容重投

日常 NAS 的直接 HTTP 验证确认：使用真实设备身份，却指定未授权 scope 读取当前合成记忆，返回 403。这只证明未授权作用域拒绝；不代替已有的两项目数据隔离测试。

新增 `scripts/probe_offline_suppression.py` 复用现有安装探针、真实 SDK 存储、设备配置及管理员治理接口。当前相同镜像在 NAS 独立禁网容器中运行；仅只读挂载四份合成探针源码，不挂载日常三卷，不使用外部模型。提炼使用合成替身，不能称为真实外部模型或两台物理主机演练。

该组合验证七项服务端结果：另一设备可先读到普通记忆；离线队列跨客户端进程保持；管理员 forget 完成；新来源、新记录 ID 的混合事件含已忘记长句时整条拒绝；重连后完整回执及任务集合不变；搜索不再返回该记忆；保留原文仍可显式读取。具体服务端拒绝为 `409 governance_content_suppressed`，退出 0，耗时 12.249 秒。测试容器自动移除，日常服务仍健康。

同时复现客户端限制：HTTP 409 被统一显示为 `remote_identity_conflict`，被拒事件及其后的一条正常事件仍在队列中，后续补传被阻塞。因此只能将服务端防复活记为通过，不能宣称客户端已完成删除规则同步、永久拒绝项处置或后续队列恢复。本轮保留实测报告及客户端阻塞证据，不操作日常队列中的既有 unknown 任务。下一步只处理此实际同步阻塞，完整日志治理、客户端离线读缓存和灾难恢复仍后置。
