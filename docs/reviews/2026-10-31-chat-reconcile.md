# 普通聊天合并输入验证

日期：2026-10-31。关联 FR-08、FR-09、FR-10、FR-11；设计见 [ADR-0025](../adr/0025-chat-reconcile-evidence.md)。

## 实现与边界

补丁 0013 在原生合并器完成链头选择、去重和提示组装后，调用已有有界快照工具，保存实际候选当时的 payload 与提示。新增可选持久结果字段，不改变原算法、模型调用和重试；旧结果缺失字段仍表示未观测。调用内状态避免并发串轮，embedding 不进入证据。提炼器的已有标签／画像字段保留参数没有进入实际提示，不虚构来源边。

架构、实现、测试和性能采用顺序自审；没有独立同行审查。额外工作为有界序列化，无新增模型或数据库读取。此证据证明模型实际候选与提示，不能证明检索成功／发现完整，也不能单凭可变 MemoryNode ID 证明生产版本。Hub 来源接线、画像／摘要／异步图、删除执行、恢复防复活及六入口两机验收继续待完成。

## 本地证据

Hub 全量 511 项通过（269 条上游弃用警告），其中新增 24 项测试；既有 lite 用例增加明确 not_used 检查。覆盖最终链头、控制去重结果后的捕获位置、结构和标签、对象后改不影响快照、成功／重试／回退、跳过、未知异常、预算／非法元数据以及同合并器并发隔离。去重算法本身由上游回归覆盖，不把控制候选的测试当作完整原生检索验证。

真实 SDK 的 add 与 add_extracted 在原生存储、检索和 writer 上验证持久结果与重开重放；模型输出使用合成 provider。8 种中英文／自定义提示／意图组合调用真实 Extractor 提示构造，验证未使用参数不影响实际消息。`make probe-chat-reconcile` 通过三进程写入／两次重开，断言持久证据相同且重放不再调用提炼或合并模型。探针首次把快照的 record 字段写成 data 而失败；修正探针后通过，产品逻辑未为此改动。

相关上游 payload-only、L1 读取边界、预处理／结果缓存、延迟、链合并／回退及提炼提示覆盖共 76 项通过。临时测试环境沿用 faiss-cpu 1.15.1、qdrant-client 1.19.1、pytest-asyncio 1.4.1，不修改产品依赖。`make check` 的格式、静态检查、19 项工程门禁、文档链接、路径与凭证扫描通过。CI 已配置探针，尚无远程运行证据。
