# 当前轮自动共享与真实模型接续

日期：2026-11-10。关联 FR-01、FR-02、FR-03、FR-05、ENG-01。接续[两台 Mac 接入](2026-11-10-two-host-mvp.md)，设计见 [ADR-0050](../adr/0050-mvp-visible-turn-hooks.md)，使用方式见[自动共享说明](../agent-turn-hooks.md)。本轮只补齐 G2 日常使用链路，不扩展旧治理范围。

## 实现与复用

新增显式工作目录绑定的 Claude hook，复用固定上游 `_messages` 提取当前用户文字和最终回复，过滤后写入现有 LocalOutbox，再尝试远程接纳。下一轮通过原有 history-list 取得最近原文并注入有限、不可信参考上下文。无 transcript 回退、历史扫描、新存储或新上游补丁；NAS 无需启用模型提炼。

同一原生 session／prompt／角色和已绑定来源形成稳定身份，重放复用事件；网络失败保留待传状态，读取失败独立报告。旧 MCP 和 CLI 合同不变，新的可见消息使用既有 conversation_turn 形式，不伪称已提炼事实。

## 真实模型按 Skill 约定使用 MCP

另一项独立探针沿用 Claude 已有认证和模型设置，以临时设置关闭普通 hooks、自动记忆和普通 CLAUDE.md，限制为本次 MCP 工具，不读取真实历史、不复制凭证。Skill 正文作为 system prompt 提供，故该项不证明原生 Skill 发现。

真实模型在同一 session 完成三轮成功结果、10 次 MCP 调用、零工具权限拒绝：保存合成决定后 Mac mini 读到；Mini 写入未出现在第二轮提示中的新标记，Claude 重新读取并在答案中使用；第三轮模型保存并读取交接，Mini 再读取同一交接。

首次驱动脚本把过滤后的交接与未规范化输入直接比较，断言失败并退出 1，随后收尾终止 Claude 进程（143）；原始失败报告保留，**不改写为整次探针通过**。对同一交接进行只读复核，五个字段全部符合生产过滤结果，差异仅为既有 NFKC 全半角规范化。另存复核证据后修正新探针比较规则；没有为这次复核重新请求三轮模型。由此可确认上述真实调用与过滤后完整交接行为，不能声称字节原样保存或原探针正常退出。
