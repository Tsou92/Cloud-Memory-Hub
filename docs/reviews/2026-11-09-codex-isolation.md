# Codex 桌面前置隔离探针

日期：2026-11-09。关联 FR-01、FR-02、FR-05、ENG-01；承接[桌面隔离调查](../research/codex-desktop-isolation-2026-11-09.md)。

## 结论

**当前候选策略未通过严格的“只允许回环网络”要求，不可作为真实 Codex 桌面的安全启动许可。** 本机 `sandbox-exec` 可以运行受限的合成进程及其 fork/exec 子进程，文件和凭证服务访问限制有实测证据；但策略中的 `localhost` 网络过滤允许连接本机非回环接口地址上的合成端点。

[可执行探针](../../scripts/probe_codex_isolation.py) 包含 34 项父／子进程断言，本次 32 项通过、2 项失败，退出码为 1。失败是需要保留的网络边界证据，不能降低断言或将非零退出算作通过。本次没有启动 Codex 桌面、app-server 或模型，没有访问真实凭证或聊天内容，没有修改日常配置，没有运行 NAS 操作。

## 实际执行边界

- 平台为本机 macOS 27.2，构建 26B123；使用系统 `/usr/bin/sandbox-exec` 和系统 C 编译器。编译一个只执行明确文件、网络及 Mach 服务查询的小型合成程序，不运行 Agent。
- 在唯一临时根中创建允许读取的测试区、禁止读取的兄弟目录、合成 `.codex`、`.agents` 和 Keychain 文件，以及指向禁止区的符号链接。测试内容均为固定合成标记。
- 子进程环境仅包含最小 PATH、合成 HOME／CODEX_HOME 和语言设置；不继承 provider 密钥、代理、后台连接或日常 Agent 配置。先在此环境下运行无 sandbox 对照，再运行相同程序和参数的受限组。
- 对真实 HOME、`.codex`、`.agents`、`Library/Keychains` 只尝试打开目录句柄，立即关闭，不列举目录、不打开其内部文件。对照均成功，受限组均返回 `EPERM`。
- Keychain 检查仅调用 `bootstrap_look_up` 查询公开的 `com.apple.SecurityServer` Mach 服务，不调用任何凭证查询、解锁、写入或认证方法。对照成功，受限组返回 `BOOTSTRAP_NOT_PRIVILEGED`（1100）。这不能替代实际桌面全部凭证路径的验证。
- 网络端点全部由本次探针在本机临时创建，包括 IPv4／IPv6 回环监听和一个绑定本机非回环接口地址的同端口监听。监听仅接受后关闭连接，不读取请求或提供数据，探针结束即关闭。没有连接远程主机，也没有发送模型请求。接口地址只用于进程内参数，不进入结果记录。

## 策略与结果

策略默认拒绝，仅读取测试区、必要的公开系统库，以及启动所需的根目录句柄；只允许执行本次生成的合成程序并 fork。没有文件写入许可，没有 Mach 服务许可。网络只配置两个精确端口的 `(remote tcp "localhost:端口")`。

| 检查 | 无 sandbox 对照 | 受限父／子进程 | 结论 |
| --- | --- | --- | --- |
| 合成允许区、公开系统文件读取 | 成功 | 成功 | 必要读取可用 |
| 允许区文件写入 | 成功 | 均为 EPERM | 本测试区保持只读 |
| 禁止区、合成敏感文件、符号链接逃逸读取 | 成功 | 均为 EPERM | 所测文件限制生效 |
| 真实用户目录句柄打开 | 成功 | 均为 EPERM | 所测目录访问被拒绝，未读取内部内容 |
| SecurityServer 服务查询 | 成功 | 均为 1100 | 所测服务查询被拒绝 |
| IPv4／IPv6 回环 TCP | 成功 | 成功 | 回环端点可用 |
| 本机非回环地址 TCP，同一已允许端口 | 成功 | **均成功** | **严格地址边界失败** |
| 本机非回环地址 UDP | 成功 | 均为 EPERM | 策略未允许 UDP；不据此证明 TCP 地址隔离 |

这些结果同时覆盖直接测试进程和由它 fork 后再次 exec 的子进程。仅环境变量隔离的负对照能够读取禁止区合成文件、打开真实目录句柄及查询 SecurityServer，因此重定向 HOME／CODEX_HOME 本身不能替代进程限制。

## 调试与负对照保留

1. 数值地址形式的 `(remote tcp "127.0.0.1:端口")` 被本机策略编译器拒绝，明确要求 host 为 `*` 或 `localhost`。系统公开策略也采用后者；本探针没有以 `*` 放宽网络权限。
2. 最初缺少根目录句柄许可，合成程序在进入 main 前以 SIGABRT 退出。系统 `/System/Library/Sandbox/Profiles/dyld-support.sb` 说明 libignition 需要打开 `/` 作为 openat 根。只新增 `(allow file-read* (literal "/"))` 后，同一无参数程序由 -6 恢复到预期的参数检查退出码 64，确认启动失败原因；没有开放用户目录。
3. 最初非回环 TCP 使用未监听端口，对照和受限组均返回 ECONNREFUSED，证据不足。加入同一主机非回环地址的合成监听后，两组均连接成功，才确认策略未满足所要求的地址限制。

失败临时目录保留合成程序、策略和结果，不能删除失败现场后只报告其他断言。本地最终摘要保存为忽略目录中的 `probe-codex-isolation-final.json`，无接口地址、个人路径、凭证或聊天内容；stderr 单独保存在本机。探针超时或被中断时只结束其自行创建的进程组，不按应用名或 bundle ID 终止进程。正常执行等待子进程结束并关闭本次监听；成功时才回收自己的临时目录。

独立代码复核发现：新会话中的测试进程不会自动随父进程的 Ctrl-C 退出。已补充 `BaseException` 收尾，终止本次进程组、等待回收，再重抛原中断。另以合成 shell／sleep 子进程实际注入 KeyboardInterrupt，验证原异常保留、父进程被回收且整个测试进程组不存在；该修正不改变上述网络失败结论。

## 重现与下一步边界

在 macOS、已安装系统编译器且具备本机非回环接口时执行：

```sh
uv run python scripts/probe_codex_isolation.py
```

没有上述前提或对照失败时，探针应明确失败，不跳过后报告通过。当前系统上预期重现两项 TCP 地址断言失败。

本次只验证了一个最小 Seatbelt 策略，没有证明所有可能的 macOS 隔离方案均不可行，也没有证明真实桌面在该文件／IPC 限制下能够启动。尚未测试远程互联网端点、Electron GUI、桌面后台、登录界面、hook 信任、已有对话下一轮、产出格式或 Cloud Memory Hub 产品接线。下一步应先补充并验证满足既定网络要求的隔离机制，再考虑启动隔离桌面；不能从本次部分通过推定这些能力已完成。
