# 普通聊天历史输入验证

日期：2026-10-30。关联 FR-08、FR-09、FR-10、FR-11；设计见 [ADR-0024](../adr/0024-chat-input-evidence.md)。

## 实现与范围

补丁 0012 在固定上游原历史解析链路跟踪消息片段的实际贡献节点；不改变原查询、排序、窗口、姓名或截断规则。新结果保存可选 `chat_history`，区分 complete、not_used、unavailable 和旧字段缺失，并保留传入提炼阶段的历史文本及节点快照。调用内状态和 512 节点／2 MiB 预算避免串轮及无界结果。

原生 L1 实测没有 request_id 标记。测试最初错误地假定该标记存在，实际 SDK 验证纠正了这项假设；保留 null，后续通过 Hub 已证明的 raw ID 产出查找生产原文。没有按正文匹配或补造标记。快照还未接入 Hub 普通聊天来源图，其他标签／候选／画像／摘要输入继续待覆盖。

## 验证证据

新增测试覆盖实际窗口、相同正文不同身份、多行和跨节点续行、姓名在窗口外／被新姓名替代、截断移除的片段、当前节点排除、空历史、旧标记缺失、读取异常、记录数和 UTF-8 字节超限、非法元数据、重复／缺失节点、同 writer 并发隔离及快照不受后续对象修改影响。

SDK 集成使用真实 writer、原始节点持久化和写入结果重放，仅用合成提炼结果替代模型处理；覆盖 pro 两次写入后重开及 lite 明确不使用历史。`make probe-chat-history` 通过三个独立进程完成三轮写入、两次重开／重放，并断言读取不再提炼。它不证明真实模型质量，也不代表 Hub HTTP 来源关系已接通。

最终 Hub 全量回归 472 项通过（269 条上游弃用警告），其中新增 23 项聊天历史用例；`make check` 的格式、静态检查、19 项工程门禁、文档链接、路径与凭证扫描通过。相关上游 payload-only、L1 读取边界、预处理／结果缓存、写入延迟及合并回归 68 项通过。首次执行有 2 失败、3 错误，均来自缺少可选 FAISS／Qdrant 测试依赖；按照上游锁文件，在临时测试环境加入 faiss-cpu 1.15.1、qdrant-client 1.19.1 和 pytest-asyncio 1.4.1 后全部通过，产品依赖未改。

本轮采用顺序自审：捕获点和原数据流对齐，节点身份跟踪而非内容匹配；只序列化有界字段，无额外模型／数据库查询。CI 增加跨进程探针，尚无远程运行证据。本地与 NAS 安装容器均已通过三进程写入／读取和 `dae8cae → c65be47 → dae8cae` 往返；另由旧镜像实际写入，再由新版重开验证旧结果仍缺少捕获字段，不推定为实际空输入。测试使用禁网、只读根目录、3 GiB／2 CPU 的独立合成卷。本地与 NAS 完整容器 smoke 均通过，覆盖初始化、认证、权限撤销、过滤投递、采集及重启持久性。常驻空实例从 `c65be47` 停服备份后升级至 `dae8cae`，再次重启后健康与认证核验通过。三个卷及部署文件已备份并校验归档／摘要；配置、业务、治理卷备份分别为 156672、676864、31232 字节。身份、凭证、模型／设备／项目／来源／回执的空基线一致，access 2、ingest 2、lineage 1、context 1、inputs 1 保持不变，无需迁移命令。

实际配置摘要／revision、原挂载、只读根目录、ALL capabilities drop、3 GiB／2 CPU 和 `127.0.0.1:8800` 绑定均已核对；最终现场状态 `running healthy`。本次未导入真实历史、激活外部模型或调整 SSH；没有执行常驻镜像回退或完整备份恢复演练，隔离卷兼容性测试不替代恢复验收。
