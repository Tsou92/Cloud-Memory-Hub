## 实现边界

文本及自由元数据在进入队列前统一过滤；未知媒体拒绝并仅计数。固定事件 ID 防止重试覆盖；库绑定实例／设备，普通打开不重建。回执匹配后才记录 `accepted`，内容处理状态另行实现。

## 验证过程

首次新增用例发现 URL 的 percent-encoded 凭证字段在重复过滤后丢失普通查询参数：上游通用赋值正则会吞掉 `&` 后的内容。Hub 将 URL 独立解析，其周边仍通过原脱敏器，保留查询参数及重复过滤一致性。随后普通 Markdown 链接测试发现结尾括号被当作 URL 参数编码，修正了不配对的闭括号边界。失败记录与后续复跑均保留在忽略日志中，没有修改上游测试以制造通过。

自审补充的 URL 嵌套 JSON 用例在修复前真实失败：参数解码后还含转义的凭证字段名，仅按纯文本处理会漏掉它。现对解码后的 URL 组成部分继续应用同一递归过滤和深度／节点限制，隐藏控制字符也拒绝；修复后原失败用例通过。原始失败记录为 `.local/local-delivery-url-regression-before.log`。

新增用例覆盖正文、工具 JSON、Unicode 转义的 JSON 键、Cookie 对象、已知凭证、敏感字典键、键冲突、大小／深度限制、媒体拒绝、固定错误、落盘不含合成原凭证、并发去重、重复／冲突回执、普通重启、异常退出、绑定错误、损坏内容和新过滤规则阻止旧内容投递。
