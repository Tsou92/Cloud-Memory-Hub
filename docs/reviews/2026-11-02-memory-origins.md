# 普通记忆生产版本验证

日期：2026-11-02。关联 FR-08、FR-09、FR-10、FR-11；设计见 [ADR-0026](../adr/0026-chat-memory-origins.md)。

## 实现与复用

补丁 0014 扩展已有 record_origin 为普通记忆生成独立域的语义版本摘要，沿用 MemoryNode、通用 payload 与原生 writer 的持久化位置。生产请求与语义状态一起写入，单条/批量 ADD、原地 UPDATE、SUPERSEDE 和直接写入均覆盖。UPDATE 使用已有旧节点读取，不增加数据库访问。旧节点读取失败则清空来源。三个原生后端对未带完整来源对的语义更新清空旧标记，辅助状态更新保留生产者。

摘要保持 experience/fact 兼容，普通记忆覆盖实际模型内容与身份/时间；旧数据缺失字段不回填。该一致性标记不是签名，也不能单独证明完整来源链。Hub 原文、唯一生产请求、作用域与阶段/产出关系仍需接线验证；画像、摘要、后台任务、删除执行与恢复防复活继续待完成。

本轮对架构、数据流、代码、错误路径、测试和性能作顺序自审，没有独立同行审查。新增开销是语义字段摘要；保留原模型调用、检索和存储后端。

## 本地测试

项目安装环境的 make check-runtime：536 项通过、5 项可选后端测试跳过，269 条既有上游弃用警告。另以固定可选依赖运行 make check-memory-origins：28 项全部通过，包含上述 5 项；跳过项没有计为原环境通过。make check 的格式、静态检查、19 项工程门禁、文档路径/链接与凭证扫描通过。

新增用例覆盖语义篡改、旧数据、节点/通用 payload 往返、非法请求和结构、完整/不完整来源对，以及三种真实本地存储 Chroma、FAISS、Qdrant 的持久化和重开。原生 writer 的合并结果使用合成操作，覆盖批量 ADD、单条/批量 UPDATE、SUPERSEDE、直接写入，以及旧节点读取异常。现有真实 SDK add/add_extracted 回归补充生产版本断言：原地更新后的当前节点归属新请求，冻结输入和重放仍归属旧请求。

make probe-memory-origins 在三个独立进程中验证两种 SDK 写入入口、原地更新、版本标记、冻结输入和重放；模型响应为合成结果。该证据不代表模型质量或六入口真实接入完成。

相关上游 payload-only、L1 边界、写入缓存/结果/延迟、链合并/回退、提示、带向量更新及克隆回归：80 项通过；1 项 Qdrant BM25 稀疏克隆因 fastembed 支持不可用跳过，未计通过。可选测试环境沿用 faiss-cpu 1.15.1、qdrant-client 1.19.1、pytest-asyncio 1.4.1，产品依赖未修改。

验证过程中修正了两个测试环境问题：Chroma 的正文更新样例补齐同维度合成向量，避免调用默认 embedding；可选依赖环境用 python -m pytest 确保后端真正加载。曾把全量测试放入临时依赖环境，2 项已安装 CLI 测试因缺少入口文件失败；这两项随后在原项目安装环境实测通过，保留其真实命令验证。CI 分别运行正式安装环境、全部可选后端和跨进程探针，尚无远程 CI 结果。
