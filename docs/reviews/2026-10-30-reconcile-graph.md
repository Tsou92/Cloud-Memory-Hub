# 合并输入来源图验证

日期：2026-10-30。关联 FR-08、FR-09、FR-10、FR-11；设计见 [ADR-0023](../adr/0023-reconcile-input-lineage.md)。

## 实现与复用

复用固定 SDK 的输入快照、原生来源标记、持久写入结果，以及既有 Hub 原文验证、类型化产出、历史输入和方向性规划。新增 `cmh_event_inputs` 独立 schema 1，与产出关系及上下文在同一事务归档，补核对只读取已完成任务的结果。固定上游没有 NAS 原文／项目身份库及这组事务，新增适配器不替代其 writer 或队列。

阶段节点为 `cmhi:<receipt>:<stage>`，核验快照摘要、生产原文、项目／agent／source、事实 session 及对应类型产出。父节点使用生产轮原文和当时已使用阶段，不连回当前可变记忆 ID；生产轮的历史上下文也纳入。used 阶段仅关联成功产出，fallback／skipped 保存为历史副本。图检出循环、缺证据、损坏／异常版本和预算溢出时明确拒绝。旧结果缺字段与真实空输入分别保存，仍不宣称旧结果完整。

管理员预览增加输入 raw 记录，授权读取补充已证明的间接原文；没有新设备权限或删除执行路由。`consistency: observational`、`execution_available: false` 不变。

## 源码与工程验证

新增实际 SDK／writer／存储用例覆盖 working／coding、连续三轮经验 ADD→UPDATE→UPDATE、事实替代和历史继承、清理队列载荷后重启、旧快照没有自引用或未来来源。另覆盖损坏摘要、跨项目／错误生产身份、未证明产出、缺阶段、错误变体、循环、fallback 副本、无来源和预算。输入归档写入失败会回滚产出、上下文及归档，随后仅凭已有 SDK 结果补核对；重复归档一致，改变证据被拒绝。

原历史上下文测试／探针的 synthetic reconciler 没有消费候选，现明确捕获空候选阶段，避免将原本 unavailable 的夹具误当作完整证据；产品的缺证据保护保持开启。源码探针通过真实 Hub HTTP 接纳、SDK 写入、归档、记忆读取和管理员预览验证经验三轮更新，两个独立读取进程不再调用 writer。模型生成均使用合成替身；事实历史的直接证据来自源码集成用例。

完整 Hub 回归 **449 项通过**（269 条上游弃用警告）；固定上游 store、经验／事实 reconciler、writer、路由和提示词语言回归 **139 项通过**，测试进程临时使用 pytest-asyncio 1.4.1，产品依赖未变。源码输入图探针和原历史／编程链探针均通过。CI 已增加独立进程输入图探针步骤，尚无 GitHub 远程运行证据。新增重复 JSON 键测试首次使用了错误的异常断言，修正为现有 PrivacyError 后通过，未放宽解析器。

`make check` 的格式、静态检查、19 项工程门禁、文档链接、路径与凭证扫描通过。目标容器与 NAS 证据待本轮执行后补充，未计为通过。审查使用顺序自审，不声称独立同行审查。

## 未完成的边界

旧 unobserved 仍不是完整依赖；普通聊天全部模型输入、已缺失物理产出的修复、在线维护排空、选择性删除执行、完整备份恢复防复活及六入口两机闭环仍待完成。输入阶段只由管理员预览读取，设备历史 API 仍只访问既有授权原文。跨存储观察不是可执行的冻结计划。
