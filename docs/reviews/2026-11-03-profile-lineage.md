# Hub 基础画像来源接线验证

日期：2026-11-03。关联 FR-08、FR-09、FR-10、FR-11、FR-12；设计见 [ADR-0029](../adr/0029-basic-profile-lineage.md)。

## 实现与评审

画像旁路使用独立 schema 1 归档及产出索引，与旧产出/上下文同事务提交；旧 cmh_event_output_links 和摘要保持不变。只登记 native result 确认的 L0 产出，核对原生 ID、用户/层/空 Agent 和会话、默认 source 与生产请求摘要；尝试但未确认的操作留在归档，不冒充产出。已完成回执支持缺档补录，旧缺字段保持 null。

来源图使用 cmhb: 内部输入节点，将旧画像候选连接到对应生产请求与规则/聊天历史。Hub 用户标识包括实例与项目作用域，跨 Agent 共享不等于跨项目授权。读取和范围观察同时核验当前画像标记，后来未记录的修改不能继承历史索引的证明。规则核对直接复用上游清洗、链头和完整 KV 函数。

共享原生节点验证和有界图遍历。普通记忆合并快照也补齐本次提炼的聊天历史父边：原来只有语义产出带该边，会遗漏提示快照中的派生内容；skipped 空阶段保持原关系。每次画像最多核验一个新节点，范围观察复用已有 payload，图共享回执缓存和预算，SQL 预检包含新增归档字节。

已顺序自审架构、代码、测试、权限和性能，无独立同行审查。输入快照的独立执行时序、后台派生任务、删除执行和恢复防复活仍未完成，execution_available 保持 false。
