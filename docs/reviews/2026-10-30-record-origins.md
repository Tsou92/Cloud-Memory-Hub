日期：2026-10-30。关联 FR-08、FR-09、FR-10、FR-11。设计及后续工作见 [ADR-0023](../adr/0023-reconcile-input-lineage.md)。

## 本次范围与审查

固定上游补丁 0011 复用经验／事实存储的 additive-column 迁移、SQL upsert 和 writer／reconciler；新增来源请求及绑定该请求的语义内容摘要。正文及两项来源字段由同一 SQL 写入，沿用原生 created_at 保留规则；快照复用补丁 0010 的完整记录序列化。旧记录不猜测来源，直接修改默认清除旧来源，旧镜像改写正文留下的标记由摘要核验拒绝。摘要是内部一致性检查，不是生产原文已验证的证明。

按工程与代码审查清单进行了顺序自审：识别并修正 ID 冲突时数据库保留创建时间但输入对象时间不同，以及事实可空文本在 SQL 中归一化为空串造成的摘要不一致。未使用独立审查 Agent，不将自审称为同行审查。未改变模型提示、模型调用次数、产出决策或隐私过滤。

## 源码验证

新增用例覆盖 working／coding 两套存储连续三次同 ID 写入、旧快照不变、普通编辑清除来源、历史事实状态／互链更新、旧 SQL 正文改写、标记／作用域／正文损坏、无效请求拒绝及原生 ADD／异常回退；既有实际 writer 的经验 UPDATE、事实 SUPERSEDE 用例同时核对成功产出的来源请求。

`make probe-record-origins` 用实际安装可复用的 SDK／writer／存储执行 working／coding 各三轮同 ID 更新，采用合成模型决策；两次独立进程重开、既有请求重放及旧快照逐项核对通过。此源码探针不等于 NAS 或真实模型验收。

完整 Hub 回归 **419 项通过**（155 条上游弃用警告），固定上游 store、两类 reconciler、writer、路由及提示词语言回归 **139 项通过**。测试进程临时使用 pytest-asyncio 1.4.1，产品依赖未变。`make check` 的格式、静态检查、19 项工程测试、文档链接、路径及凭证扫描通过。
