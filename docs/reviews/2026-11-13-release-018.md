# 0.1.8 发布记录

日期：2026-11-13。版本 `v0.1.8`，源码提交 `483ed6f`。

## 范围

界面与可用性修复 11 项，能力补齐 6 项。全部复用已有后端能力，不新增协议或存储。

### 界面修复

- 记住所选项目（按实例隔离），单一项目自动选中，刷新不再回到「请选择一个项目」
- 顶栏与侧栏连接状态改为真实读取结果，NAS 不可达时显示「无法连接 NAS」
- 会话失效时提供「重新登录」入口，不再只有注定失败的重试
- 记忆库空态说明原因（未配模型 / 待整理 / 去历史原文核对）并给出下一步
- 影响范围面板新增「彻底删除」，与「忘记」明确区分，仅在证明完整时可确认
- 备份页给出可复制的导出／恢复命令，并说明为何不能在网页执行
- 登录页改称「管理员密码」，首次初始化页给出可执行步骤
- 新增 `reset-admin-password --writers-stopped` 离线重置
- 后台常驻「实验版本」提示，新增《数据会去到哪里》
- 页面标题与控制台侧栏统一为 Cloud Memory Hub
- 采集守卫不再把内嵌 JSON Schema 的普通工具结果误判为媒体

### 能力补齐

- **记忆库语义搜索**：接入已存在的项目内搜索
- **历史原文关键词搜索**：新增 `history-search` 读取操作，复用忘记／删除抑制
- **记忆纠正**：先校验项目归属再写入，跨项目零写入有测试证明
- **用量展示**：设置页显示模型请求次数与 token，明确不是账单
- **历史导入说明**：服务端无法扫描本机文件，给出可复制命令而非死按钮
- **跨项目检索**：按 ADR 写清切换到「全局偏好」，不做违反隔离的「全部项目」
