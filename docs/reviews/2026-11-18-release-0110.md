# 0.1.10 发布记录

日期：2026-11-17（补记于 2026-11-18）。版本 `v0.1.10`，源码提交 `0665d83811c6de92e9c7770ff83ce2e027dae7fd`。

## 范围

- 费用估算：按审计库中的模型、token 与请求时间估算金额，覆盖 Claude、DeepSeek、OpenAI 与 Gemini 的常用模型；DeepSeek 按官方峰谷规则分时计价。未知模型明确列为未定价，可用 `CMH_MODEL_PRICES` 覆盖单价或补充峰谷规则。
- 用量汇总兼容形状：审计库把总计放在 `summary` 下，网页读的是顶层字段；接口现在同时给出两种形状。
- 传输错误按异常类型重试：不再依赖错误文本里是否含 “connection”，DNS 解析失败等消息也能正确重试。
- 发行工具：创建草稿后等待 releases 列表可见，修复 `release_draft_not_found` 竞态（PR #25）。
