## 上游问题与归因

1. `test_live_capture` 的测试替身错误地要求并断言 `source_admitted=True`，而实际队列按正式方法默认值 `False` 调用，以保留来源授权复核。最小测试补丁及证据见[补丁说明](../../upstream/patches/README.md)，未修改生产授权语义。
2. `test_active_credentials` 的 deactivate／switch／revision 三个参数场景引用旧错误码；按当前方法合同修正测试，保留并发身份拒绝断言。
3. `test_active_memory_window` 两个连续摄取旧任务用例仍把 migration 054 已删除的表当成授权依据；改测旧表不能绕过当前窗口，以及已有全历史选项下旧记录可调度且不占写锁。两个文件与 migration 054 共 25 项通过，详见补丁说明。
4. 扩大到整个迁移测试文件后，仍有六个既有失败：期望连续迁移编号但 39／48 已退役、引用已退役的 preview／processing_requests 表、向两列快照表插入旧三列结构。这些仍待归因和处理。

上述问题保留为原基线的失败记录，不用定向回归抵消。随后独立验证了上游 SDK 权威存储版本，按照 [ADR-0003](../adr/0003-sdk-authority-baseline.md) 切换隔离开发基线；旧两个补丁未应用到新版本。
