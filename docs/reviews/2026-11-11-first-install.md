# 一次首装验收

2026-11-11。关联 [ADR-0070](../adr/0070-first-install.md)。

使用正式 v0.1.4 制品，在实际 Linux amd64 NAS 上以独立 Compose 项目和空卷启动。NAS 直接下载出现 TLS 连接中断，验收使用同一版已校验的本机制品通过 SSH 传输，NAS 再校验。真实 Docker 和回环健康通过，新建的私网 HTTPS 地址返回 200。首装命令自动创建项目、签发并领取邀请、安装正式 Mac arm64 客户端和 Codex 项目钩子。用户界面状态为等待宿主信任。

隔离的真实 Codex app-server 审核并信任了两条项目钩子。两个普通会话触发四次钩子，NAS 接纳两边问答，第二个模型请求读到第一个会话摘要并答出随机测试值，可按摘要锚点读回该会话 Markdown。验收使用本地测试模型，NAS 未配置长期记忆生成模型。真实 Codex 桌面 v0.1.4 的接续此前已独立验收，本次未重复操作桌面 UI。

NAS 资源冲突、初始化一次、续跑和原私网监听保护另外使用合成 Docker 与网络命令验证。其他平台或宿主的逐轮自动收发范围沿用正式发行版。
