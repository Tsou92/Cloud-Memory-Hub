# 合并决策输入快照验证

日期：2026-10-29。关联 FR-08、FR-09、FR-10、FR-11。

## 实现与证据

固定上游补丁 0010 复用生产力 writer、原生候选格式化和历史预算，在实际经验／事实决策、历史摘要及 details 继承处记录快照，并随原 SDK durable result 持久保存。设计和兼容性见 [ADR-0022](../adr/0022-reconcile-input-snapshots.md)。不增加模型调用、运行数据库或 SDK 结果表迁移。

16 项集中测试通过。实际 SDK、CodingMemoryStore、经验 UPDATE、事实 SUPERSEDE、历史摘要／继承和结果重开均有覆盖；模型生成决策为合成替身。验证原地更新后仍保存旧正文与旧状态，实际呈现片段和完整快照分离；超限／非法对象／未完成阶段不得变成部分 complete，两个并发调用不会交换输入。按预算被排除的 details 不出现在入选记录中，异常文本不写入新增捕获字段。

完整 Hub 运行时回归 405 项通过，136 条上游弃用警告。固定上游经验／事实 reconciler、writer、场景路由和提示词语言回归 98 项通过；测试进程临时使用 pytest-asyncio 1.4.1，没有改变产品依赖。首次夹具缺少 tool 消息，按上游规则进入聊天路径并失败；修正为合成工具输入后重新验证，没有修改产品路由。

独立进程源码探针通过 working／coding 两条路径：实际更新旧经验，保存其更新前输入；连续两次新进程读取及相同 request_id 重放返回相同快照，不重新提炼。此项为源码运行证据，安装制品及 NAS 证据在实际执行后补充。

## 自审与剩余边界

实现者按架构、数据安全、并发、测试和性能检查差异，未进行独立同行审查。捕获按每次 write 分配，不使用共享成员状态；原生记录经 JSON 深拷贝，整项捕获同时接受条数、阶段数和最终序列化字节预算。保持原来的模型错误回退和持久写入行为。保留完整记录用于核对版本；只有 rendered 字段表示该阶段实际格式化的输入片段，skipped 不表示已调用模型。

complete 只表示本文列出的生产力合并阶段已经捕获，不代表全部 SDK 模型输入或完整治理范围。output_id 是该阶段的目标事实 ID，必须结合实际成功产出核对，不能单独证明 INSERT 成功。Hub 尚未把这些快照合并为可执行的来源关系；旧结果字段缺失也不能当作空输入。普通聊天、选择性忘记／彻底删除、自动备份恢复和六客户端两机闭环仍待完成，现有治理预览继续 `execution_available=false`。
