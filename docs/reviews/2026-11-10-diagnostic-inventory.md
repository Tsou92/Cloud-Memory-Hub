# 旧诊断文件：只读范围检查验证

日期：2026-11-10。关联 FR-10、FR-11、ENG-01。设计见 [ADR-0042](../adr/0042-diagnostic-file-governance.md)。

## 本步交付范围

新增无正文的完整请求 selector、旧记录的精确字节摘要分类、两个实际日志域的有界只读扫描。保留原取消执行的同锁证明与 CAS；准入 witness 刷新默认兼容，新增只读调用不会补写缺失 witness。未改变 execution schema、意图签名、HTTP 协议或现有 purge 完成条件。

原生日志没有逐行来源签名，因此 request 匹配只建立候选关联。后续执行须把具体 RecordGrant 集合纳入明确预览和签名意图。当前 `authorized` 分类仅核对调用者提供的精确 grants，并不验证治理主日志，也不执行删除。恢复同字节记录能识别为相同候选；被改写的记录、未选旧正文、独立读取或未知结构拒绝给出完整可清理结论。

尚未接入文件替换、活动 handler 重开、持久清理进度、schema 迁移、完成状态重放或管理界面；不计为旧文件已清理、完整删除完成或 G1 退出。

## 复用与实际路径

上游 manifest 保持原 21 个补丁，SDK 默认日志行为未变。复用真实 PipelineLogWriter、SingleLineFormatter、JsonLineFormatter 和 strict-v1 投影。测试使用独立子进程生成旧正文，关闭旧 writer 后才启用 strict；没有在正在运行的 Hub 内降级策略。

固定 Core 正常把 SDK 服务日志和 pipeline 日志写到同一个 `hy-memory/governed-v2/logs` 根。扫描器将共根的白名单合并，每个文件只扫描和计数一次，保留两个域标签；也支持显式分根。其他路径、未知文件、软硬链接、非普通文件、跨设备和扫描期间变更均拒绝。缺目录只表示指定域当前缺失，不等于所有可能副本不存在。

## 本地检查与独立审查

- 完整请求 selector 新增 21 项；连同准入和在途执行既有相关回归，86 项通过。包括完整表与 head 不变、缺失/落后/超前/篡改 witness、正文已清理恢复、证书集合、无正文不可变返回、query_only 意外写入拒绝及 CAS 内真实竞争写锁。
- 原生记录分类 53 项通过；独立审查另执行 228 项私有边界探针，对自由正文、伪 strict、异常类型、嵌套、重复键和截断未发现错误的 keep 结果。私有探针不算正式 pytest 数量。
- 文件域扫描 41 项通过；覆盖真实共根/分根、原样轮转重复、精确 grant、六类预算、日期、路径攻击、目录与文件变更、缺失路径出现和退出时关闭 fd。异设备拒绝使用受控 stat 故障注入，未宣称真挂载测试。
- 新集成探针使用真实 HTTP 接纳、签名库和 Core 队列，检查两条完整请求及六条原生旧正文记录，保留两条 strict 元数据。递归识别合成实例中的 SQLite 数据库，并显式核对 main/access/主治理/准入/SDK cache/Chroma 均在前后快照中；原始诊断字节也保持不变。未选请求和缺少 grant 均拒绝，没有外部模型调用。

审查中修复了两项实际差异：初稿拒绝真实共根日志布局；四个不带 READ_ 前缀的原生读取步骤被误作写候选。新增真实共根成功/失败测试、GET/LIST/GET_USER_PROFILE/GET_BASIC_INFO 拒绝及 SEARCH_QUERY 写链正例。另修正了祖先目录无关链接计数变动引起的误报，并补齐集成探针原先遗漏的嵌套 SDK 库快照。上述问题不是靠放宽覆盖或忽略未知记录解决。

首轮全量为 1215 通过、5 跳过、1 失败；执行期间新增的最终共根/读取/祖先回归不全包含在该计数中，因此不作为最终结果。唯一失败来自测试命令使用相对 PYTHONPATH：CLI 子进程切换临时工作目录后加载了旧 editable SDK，缺少新诊断模块。独立复现确认相对路径失败、显式绝对源码路径通过，合成正文均未泄漏；未修改旧上游、虚拟环境或测试断言。最终全量使用绝对路径重跑。

最终本地 Hub 全量 **1227 通过、5 个可选后端跳过、290 个既有警告，耗时 196.53 秒**，没有预期失败项；新增 116 项均包含在最终全量中。`make check` 的格式、静态检查、19 项工程测试、路径/凭证与差异检查通过。
