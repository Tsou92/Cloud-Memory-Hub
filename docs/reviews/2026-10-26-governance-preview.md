# 治理范围观察接口：实现与验证

关联 FR-03、FR-07、FR-09、FR-10、FR-11、FR-12。按 [ADR-0012](../adr/0012-governance-scope-and-lineage.md) 实现[管理员预览接口](../governance-preview.md)，当前仅观察显式保存的关联，不提交治理意图或执行删除。

## 实现与自审

- 复用固定 SDK 2.0.5.dev3 的 Chroma 工作线程池、ID 映射／元数据解码、Kuzu 参数查询，以及已有管理员认证、同源限制和凭证过滤。没有复制存储引擎或修改上游源码。
- 普通读取缺失单一原文指针、旧版本和归档图派生，并会把部分图查询失败变成空结果，因此增加严格存储适配；缺口及适配行为由同一个真实 SDK 探针验证。
- 先追溯选中记录及演化版本的来源，再向派生方向传播；不追溯附带摘要的其他独立来源。循环与重复关系去重。
- 审查修正两处兼容性：上游用空字符串保存空版本数组；非 UUID 记录 ID 会映射为存储 UUID。严格处理这些已知编码，同时拒绝坏 JSON、重复键、缺失身份和跨后端归属冲突。
- 同 ID 的归属冲突通过读取 ID／归属核对，其他项目正文不会取出并返回。缺失引用、图存储不可用和扫描超限显式失败；不会输出截断的完整范围。
- 预览摘要使用独立域 HMAC，分页变化返回 409；正文先过滤后截断。SDK 和格式化线程均等待实际结束后释放并发名额，取消请求不能不断遗留后台扫描／过滤任务。
- 本次是自审，未进行独立同行审查。没有新增持久数据库格式；执行、暂停写入、恢复协调与选择性抑制仍未完成。

1. `make check`：格式、静态检查、19 项工程门禁、文档路径及源码凭证扫描通过。
2. `make check-runtime`：232 项通过，其中新增 15 项预览测试。真实 Core HTTP／SDK 合成数据覆盖旧版本、归档摘要、共享来源方向、原文指针、非 UUID ID、项目与管理员边界、浏览器 Origin、分页／新增派生／正文变化、跨截断过滤、缺失／坏引用、扫描超限和并发取消。
3. `make probe-sdk-governance-links`：隔离子进程启用真实 Kuzu，验证归档派生和单一原文指针纳入范围、查询故障不吞掉、同项目内容冲突和两种跨项目后端身份冲突均拒绝。没有启用 NAS 常驻实例的图存储。
4. 使用 Hub 锁定环境、临时补充 `pytest-asyncio==1.4.0` 运行上游 `test_chroma_list_by_user_filters.py`、`test_models.py`：40 项通过。未改锁文件，不把这两组表述成整个上游回归。

测试只使用合成数据，没有调用外部生成模型。私有原始日志保留在忽略目录，仓库不存真实记忆、设备凭证或部署配置。
