# 0.1.9 发布记录

日期：2026-11-17。版本 `v0.1.9`，源码提交 `1752d07a896563fa20b92d76a2cf23e34ff7281f`，Release ID `448125521`，公开时间 2026-11-17T04:23:05Z，latest 指向本版。

## 范围

修复 0.1.8 在真实部署上不可用的三处功能，并新增两道门禁。

### 功能修复

- **记忆纠错**：后台「保存修改」每个请求都 503。纠错接口把 `RemoteRead.bridge` 工厂当实例调用，且 `UnifiedReadBridge` 没有 `update`；现在按生产接线调用工厂，并拒绝原始原文与 productivity 只读投影。
- **历史原文搜索**：SDK 把原始块一律存为 `shadow`，搜索只召回 `ACTIVE`／`SUPERSEDED`，按 SDK 召回实现永远返回 0 条。改为直接检索 Hub 的 `cmh_event_receipts` 归档，保留项目范围、忘记／彻底删除抑制与当前修订过滤；翻页按归档的 has-more 判断，不再有 50 条窗口。
- **入库凭证复核**：粘贴进对话的管理员密码与加密密钥此前会落库并送入外部模型提炼，现在在接纳阶段返回 422 且不回显。
- **会话摘要**：排除当前会话的条件下推到 SQL，长会话约 24 轮后不再挤掉其他会话的接续摘要。
- **connector**：带 `next_offset` 的搜索回复不再被判 `remote_read_mismatch`。

### 门禁与安装体验

- 发布校验新增「CHANGELOG 必须有对应版本标题」。
- DSH 插件的 5 个测试进入 CI；网页测试清单补上 `HubUsage.test.tsx`。
- 安装器完成时打印安装目录；README 与 NAS 文档补上 `curl`、`sha256sum`、`tar`、`flock`、`python3` 前置条件；初始化页给本机 Docker 用户可执行入口；Windows 引导脚本补 `-ServePort`。
