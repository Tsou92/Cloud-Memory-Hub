# 治理身份绑定与运行时隔离验证

日期：2026-10-25；2026-10-26 补记 NAS 返回结果和连接复核。需求：FR-06、FR-09、FR-10、FR-11、FR-13、ENG-01。状态：运行时接线已完成本地及 NAS 隔离容器验证；常驻实例未迁移，不是产品治理或完整同步验收。

## 复用与实现

复用固定 MemHub Core、来源授权回调、持久队列和已有独立治理记录。新增权威绑定只保存 ledger_id 与签名水位；正文和原始记录仍属于 SDK。设计、迁移及回滚边界见 [ADR-0011](../adr/0011-governance-authority-and-offline-sync.md)。

身份库版本 1 显式升级至 2，保留设备及授权；普通启动不创建缺失身份／治理库。独立治理卷不能嵌入业务或配置目录。Core 构造、lifespan、所有 HTTP 请求与响应输出均检查治理状态，来源授权回调在故障时拒绝后台新提炼。直接 SDK 删除入口返回明确 409，不能绕过新的治理合同。
