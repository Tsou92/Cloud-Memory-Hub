# 用户后台界面更新合并验收

日期：2026-11-12。关联 FR-12、ENG-01。

## 范围与复用

用户在独立编辑副本中调整了后台布局、元素位置、交互和显示信息：自定义下拉 `HubSelect` 替代原生菜单，总览指标卡、设备行、协作网络节点可点击并打开详情浮层 `HubCardOverlay`，侧栏 NAS 卡片改为「当前项目／部署版本」，子页面增加统一标题与副标题，问记忆空状态提示，模型单卡配置测试成功后显示确认条并由「完成」关闭。

副本基线为 Hub `33797cd`（41 个补丁）。当前 main 另有 0044–0046；0044 的样式已包含在用户副本中，0045 的项目目录逻辑保留在 `hub-invitation.ts`。以补丁 0047 接入，按用户要求保证前端不变：补丁后的 22 个网页文件与用户副本逐字节一致。仅副本使用的预览服务 `ui-copy-preview.ts`、交接说明与补丁未进入产品。

## 后端适配

前端调用的所有 `/hub/v1` 与 `/api` 接口在后端均已存在，无需新增路由。真实后端联调发现一处数据缺口：总览「近期活动」和交接浮层按记录时间显示日期，但官方客户端上传的原文不带 `occurred_at`，后端返回 `memory_at: null`，页面一律显示「时间未提供」。

`SourceHistory` 现在在原文没有客户端时间时，返回 Hub 实际接纳时间；取值与总览趋势图相同（`memory_write_jobs.created_at`，并校验 job 与接纳回执一一对应）。读取失败只省略时间，不影响原文读取；原文正文、摘要和权限不变。客户端自带时间时仍优先使用客户端时间。
