# 自动会话接续验收

日期：2026-11-11。设计见 [ADR-0069](../adr/0069-automatic-session-handoff.md)。

本机使用两个独立的真实 Claude Code 2.1.322 进程，在隔离项目中由产品安装入口写入项目钩子；没有替换用户日常配置。普通对话共三轮，未使用显式记忆或交接指令。B 的模型请求先收到 A 的接续摘要和会话锚点，按需读取 Markdown 后还原两条可见消息；A 原来的会话下一轮收到 B 最新进展。真实 loopback Hub 接纳和读取，生成模型为本地替身，约 5.2 秒。`make probe-automatic-session-handoff` 可复验。

合成测试覆盖原任务与授权、同项目不同来源的会话身份、忘记和彻底删除、较长原文分页、旧 Hub 兼容、重复捕获、离线待传，以及安装复用、发布包摘要和归档边界。长文续页从类似 JSON 的正文片段开始时仍可完整读取，不把单个 Markdown 片段当作 JSON 文档。

Codex 使用官方 `turn_id` 与项目钩子信任合同，已验证合成事件和安装配置；Codex 桌面自然运行、发布包首装、真实 LaunchAgent 补传、两台物理设备和生产 NAS 均未在本轮复验。摘要是从已接纳原文得到的接续摘录；长期记忆整理沿用当前模型。Markdown 完整度以已授权并已采集的可见正文为准。
