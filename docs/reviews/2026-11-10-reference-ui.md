# 参考图后台与官网改版验收

日期：2026-11-10。范围：FR-01、FR-03、FR-10、FR-12、ENG-01；设计见 [ADR-0066](../adr/0066-reference-dashboard.md)。

## 变更

后台采用深蓝紫侧栏、四项指标、设备／协作网络／近期活动和三张下方卡片；连接数量来自当前项目的有效来源。已接入不代表实时在线，光点是共享链路示意。记录数是接纳事件数，不冒称模型已提炼的记忆条目。原模型、记忆、原文、接入、问答、忘记与备份组件继续复用。

登录与一次性连接页仅调整视觉；图片采用固定公共资源路径，保持 Host/Origin 边界，不新增任意文件读取。数据库与设备协议无需迁移。

## 本地结果

- `make check`：113 项仓库测试，107 通过、6 跳过；格式、静态检查、路径和凭证扫描通过。跳过的可选宿主条件不计为通过。
- Hub 受影响接口、边界与原控制台回归：31 通过。覆盖项目隔离、管理员／同源、分类、重复回执、时间缺失、删除屏蔽、损坏权限／缺失设备、分批计数和最终读取超时。
- Web 官方隔离回归：16 文件、247 通过、0 跳过；生产构建通过，10 个改动文件 Biome 零警告。构建仍提示单个 JS chunk 超过 500 KB，未将其描述为性能基准通过。
- 实际 wheel 已检查包含与源文件字节一致的光球 PNG。Docker 精确白名单和安装包资源断言已加入；安装镜像验证另由发行检查执行。
- 真实本地 Hub 使用合成项目、2 台演示设备、4 个注册来源与 12 条接纳事件；页面统计与这些记录一致。未配置或调用外部模型，未读取日常历史。
- Chrome 后台检查覆盖 1672×941 桌面、390px 手机、项目切换、导航与刷新；无水平溢出或脚本错误。减少动态效果时 4 个光点隐藏，4 个节点仍显示。最终桌面三排起点约为 192／311／616 像素。
- 官网第一轮 Chrome 检查覆盖桌面、390px 手机、菜单、节点切换与部署指南，无水平溢出或脚本错误。后续新增的多人光标动画需独立验收，不能用这轮结果替代。

## 审查与边界

独立只读审查发现并修复：静态图片未进入 Docker 构建白名单、损坏 grant 可能被 SQL 当成有效连接、最后一次队列读取结束后未复核超时、刷新失败时备份卡片仍显示旧的绿色成功状态。复用既有 ScopeGrant、Core 只读连接池和备份错误文案；后者以“上次确认”标记旧值并覆盖 503／401 回归。最终只读复核未留本次范围内的发布阻断。

本地浏览器与合成数据不等同于 NAS 已更新或公开发行完成。完整 CI、镜像、NAS 更新、官网最终发布及动画验收结果在完成后补记；本版按用户要求不再进行 Mac mini 真机测试。
