# 写入结果来源关联验证

关联 FR-02、FR-03、FR-08、FR-09、FR-10、FR-11、FR-12、ENG-01；设计和兼容性见 [ADR-0018](../adr/0018-typed-output-provenance.md)。这是实现者自审，未进行独立同行审查。

## 实现与复用

复用 SDK 持久写入结果、真实存储和 Core 原有执行／未知结果核对流程，在配置库原子保存已核验的类型化输出关系。普通记忆、工作／编程经验及事实可以返回已接纳原文的 `cmhe:` 引用；原文仍需独立的历史读取权限。SDK 写入成功但关系事务失败时保持 unknown，后续只核对结果，不重新调用写入模型。已清理冻结输入的旧完成任务利用归档逐批补齐。

上游补丁 0008 在 SDK 实际选择 writer 后记录变体，避免相同原生 ID 跨库混淆；经验和事实同 ID 仍是两个独立输出。SDK 与 Core 一同从固定源码构建，构建工具锁定版本。实际执行测试发现 Core 完成清理引用了已退役 Evidence 门面，同一补丁改用既有 SDK 暂存存储。

配置新增独立关系扩展版本 1，不修改接纳版本 2。未知或不完整扩展拒绝启动。旧原文镜像可以忽略新增表，返回新镜像后补核对；这不是原文或治理数据的下迁移，也不意味着旧镜像有相同来源能力。

## 验证进展

- 新增 14 项测试覆盖三种场景的实际 Core 执行回调、关系事务失败和未知恢复、旧完成任务补关联、零产出、多轮同输出关联、类型碰撞隔离、进程重启、范围权限和损坏拒绝。最新关联／核对集中回归 52 项通过。
- 类型碰撞处理和边界检查完成后的最终运行时回归 334 项通过，55 条上游 utcnow 弃用提示，没有跳过项。`make check` 的格式、静态检查、19 项工程门禁、文档链接、路径和凭证扫描通过。
- 固定上游 Core 队列及 bridge 回归 236 项通过；固定 SDK 场景／writer 路由回归 54 项通过。首次 SDK 命令指定了不存在的测试文件，未执行测试；纠正路径后得到上述结果。
- 本地独立进程探针通过真实 SDK 数据存储、未知结果恢复、终态清理后来源读取及完整原文分块读取；提炼使用合成替身，没有调用外部生成模型。
- 修改共用探针辅助函数后，原有未知结果恢复独立进程探针再次通过，四类 SDK 输出均无需重发写入或初始化 coding writer 即可恢复。

早期失败分别揭示旧格式迁移夹具未移除新增外键关系，以及 Core 清理门面错误。前者仅修正合成夹具，后者修复实际运行路径；未降低验证要求。提交检查还发现补丁空白上下文的行尾空格，调整补丁表示后重新通过固定源码校验，应用后的上游源码未改变。

## 安装与 NAS 隔离验证

构建 `cloud-memory-hub:dev-e2eeb16`，对应运行时提交 `e2eeb160412c7031f23dd4e6b625198879e02bea`。镜像配置摘要 `sha256:5ce98fe2c2088c2f159095d993c0afb35323e23a8c0a4e6030babe70192c9175`；归档 261238784 字节，SHA-256 `0ac07b28501af3c8b535443dadb60067ebd89da28e28e1032c0d84005f88e49f`。NAS 已核对归档、加载后配置摘要、linux/amd64 和 revision 标签。构建代理未写入最终环境；SDK 许可证随安装包保留。

本地和 NAS 均以已安装 Hub／SDK 执行独立进程探针，确认三个场景、五种记忆输出的来源可读，未知任务无需重新写入即完成，真实队列清理后仍能分块读取完整合成原文。再次启动独立进程后结果不变。

另在一次性合成卷中执行新镜像建库及来源读取，再切到前一原文镜像 `e7450b5` 读取所有原文，最后回新镜像确认所有关系仍可读。使用禁网、只读根文件系统、3 GiB／2 CPU 和独立卷；没有把旧镜像缺少的新能力称为功能等价回退。旧镜像期间新增任务的补关联由运行时集成测试覆盖，此处没有声称完成该镜像间写入场景。

两地完整容器 smoke 均通过：禁网模型编码／分词、初始化、维护租约、认证、设备／来源授权、过滤上传、幂等重放、真实 SDK 读取、治理预览、已安装采集／召回 hook、重启及撤销后拒绝。独立探针和 smoke 的临时卷已随本次脚本清理。

NAS 常驻空实验实例已从 `e7450b5` 升级至 `e2eeb16`：升级前确认没有记忆、真实模型配置、设备、非全局项目、来源或接纳回执，且没有其他运行容器占用三个卷。停服后备份并核验 data/config/governance 归档及部署文件，再更新镜像。启动创建关系扩展版本 1，接纳及身份版本仍为 2；再次重启后健康，实例身份、凭证摘要、挂载、localhost 端口绑定、只读根文件系统、cap-drop ALL、3 GiB／2 CPU 均保持一致。

常驻实例未执行旧镜像回退或备份恢复；前述镜像往返只在独立合成卷验证。未导入真实历史、激活模型或修改 SSH 设置。此处的人工停服备份不能代替尚未交付的自动版本备份和完整产品恢复流程。

## 自审边界

直接输出关系按整轮输入归档，不伪造逐句来源。引用继续受既有数量限制并报告截断。空引用不能证明没有来源；关系记录被整体删除时，此查询不是全库完整性审计。

完整演化、共享摘要、fact_link、经验事实互链及治理范围合并仍待完成，因此当前索引不能直接充当完整删除计划。六客户端、两机下一轮同步、一分钟目标、真实提炼质量、纠错、选择性忘记／彻底删除、自动备份和完整恢复仍需分别交付与验收。
