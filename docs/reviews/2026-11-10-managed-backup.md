## 实现

- 完整三卷版本复用固定上游 Core SQLite 备份和 Hy 本地 SDK 快照；私有暂存中合并已提交 WAL，源文件不改。清单校验长度、摘要、实例、治理绑定和文件集合；未完成目录不列为成功版本。
- 容器父进程正常停止原 `serve`，获得三卷租约后备份，再恢复服务。持久计划、手动请求和保留数在独立 `/backups`；默认关闭。无需宿主 cron、sudo 或 Docker socket。
- 保留清理仅删除已验证的本功能完整版本，单项失败另行报告；快照失败不影响既有版本。状态文件写失败时服务保持可用，调度至少冷却 60 秒，并在写盘恢复后保存待写终态。
- `serve` 显式保存正常 SIGTERM 退出处理，以适配锁定 Uvicorn 完成 lifespan 后重抛原信号的行为；不把任意 `-SIGTERM` 当作成功停机。启动时已有到期计划／请求先冷备，再启动子进程。
