# 派生写入生命周期验证

日期：2026-11-04。关联 FR-02、FR-04、FR-10、FR-11、ENG-01；设计见 [ADR-0030](../adr/0030-derived-task-lifecycle.md)。

## 根因与变更

上游滚动会话摘要通过 create_task 启动，writer 没有保留或等待其句柄，正常／失败／提前返回都可能在摘要仍运行时结束。SDK 的终态回执和 Hub 的共享准入以调用返回为边界，因此不能把该返回当作派生写入也已结束的证据。原图投影的直接 await 还会把调用者取消传播到任务。

补丁 0016 仅修改 writer：会话摘要使用请求级任务列表，图投影沿用原句柄；最终收尾等待两类任务，提前图等待仍保留。shield/gather 保持本次任务强引用并等待全部结果，重复取消在收尾后传播；子任务自身取消也等待同请求的其余任务后传播。普通摘要／图异常维持原非致命合同，直接原生取消后的 SDK 结果保持 unknown。extracted writer 的耗时现在包括收尾。

按架构、代码、安全、测试、性能顺序自审，无独立同行审查。没有更改摘要／图算法、数据库 schema、用户开关或结果字段；主流程期间仍并发，各请求只等待自身任务。本文不把进程内收尾当作完整的来源证明、崩溃恢复或删除能力。

## 已执行验证

修复前四个回归场景均复现“writer 已返回，摘要尚未结束”；修复后通过。首次复现夹具遗漏了 writer 的 graph_store 字段，补齐夹具后确认四个失败均来自目标时序断言。

- 生命周期与 Hub 准入专项 28 项通过：正常和异常返回、两种入口的提前返回、重复取消、图任务失败／取消与其他任务收尾、多个摘要、并发请求隔离、禁用开关、提前图等待、实际 SQLite 写入结果及 unknown 重放拒绝。
- 上游 episode、write_outcome_client/cache、async_executor、memory_graph、workload_concurrency：164 项通过，4 项需要 Neo4j 的测试跳过；可用的 Kuzu 图用例通过。测试单独使用上游锁定版本 pytest-asyncio 1.4.0，不修改产品依赖。跳过项不计通过。
- make probe-derived-lifecycle：真实 Core/bridge/SDK/向量库、合成提炼与摘要写入；摘要完成前回执保持 running、维护不放行，取消 bridge 后等待底层同步 SDK 完成。最终成功回执和摘要经三进程重开、无提炼重放保持。直接原生取消与 bridge 外层取消的终态差异已分别验证，不能混为一谈。
- 最终 make check-runtime：634 项通过，5 项可选向量后端测试跳过，269 条既有上游弃用警告。make check 的格式、静态检查、19 项工程门禁、文档链接、路径与凭证扫描通过。
