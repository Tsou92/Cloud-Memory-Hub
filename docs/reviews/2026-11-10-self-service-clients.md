# 自助配对与 Mac 客户端发布验证

关联 FR-01、FR-02、FR-03、FR-06、FR-07、FR-12、ENG-01，以及 R2-01 至 R2-05、R3-04。设计见 [ADR-0060](../adr/0060-self-service-pairing.md)，用户入口见 [Mac 自助接入](../client-installation.md)。本轮属于产品发布主线；参赛工作仍在独立分支。

## 已实现的边界

- 网页使用现有项目、设备、授权、来源、轮换和撤销 API；不增加身份数据库或新的凭证协议。下载文件仅绑定一个设备、项目及来源。
- `cloud-memory-setup` 校验下载文件，实际检查会话与来源权限后创建私有配置和队列。相同绑定重复导入保留队列，其他绑定显式拒绝；不修改用户正在使用的 Agent 配置。
- MCP 配置可输出通用 JSON 或 Codex TOML，只含已安装命令与私有配置路径。
- Mac 后台服务复用 connector watch，提供安装、启动、状态、停止及卸载；负责已入队事件补传，不代表历史自动采集或离线读取。暂时失败由现有退避处理，永久错误停止；没有无限重启策略。
- 安装包从固定源码生成三个非 editable 业务 wheel，携带公共 Skill、哈希锁与来源声明。源码发行依赖在构建阶段预构建，安装端只下载锁定 wheel；需要本机 Python 3.12 和网络。上游完整 Python 依赖暂保留，不另写过滤、解析或队列。
