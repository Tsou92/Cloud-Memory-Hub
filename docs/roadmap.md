## 范围与依赖

G0 只建立工程基线；当前已按用户授权通过 SSH 在 NAS 的独立 Docker 项目中部署测试。仍不接管日常客户端设置、不导入真实私人历史、不激活收费模型或创建公开远程仓库；后续正式接入按已确认范围与具体配置推进，不因当前未执行而取消。

未来必须明确的信息：NAS 与另一台 Mac 的实际访问方式／运行环境、模型提供商和配置方式、GitHub 仓库归属／可见性及项目许可证。只有进入依赖这些信息的工作时才需要补充，不阻塞本地工程准备。

不纳入本产品：工作文件同步、跨 Agent 原生会话格式强制转换、自动第二站点备份、替用户修改原 Agent 历史或已自行保存的导出副本。
