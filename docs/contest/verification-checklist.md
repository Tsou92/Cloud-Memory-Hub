## 2. 参赛 Skill 的独立条件

- [ ] 获得能够接入自建 Hub 的官方 Uliya 调用方式及权限依据；仅有通用 MCP 文档不算。
- [ ] 按官方注册专家和真实能力编排，覆盖成功、失败、取消、等待用户和等待批准；不虚构接口。
- [ ] 独立安装包仅含 `SKILL.md` 与允许的 Markdown references；外围 README 和本清单放在包外。
- [ ] 核对名称与描述、单文件 ≤1 MiB、总计 ≤10 MiB、文件数 ≤100；无脚本、可执行文件、链接逃逸或占位内容。
- [ ] 官方检查器没有必须修改项，并在实际支持的环境完成安装与调用；两类证据分别保留。

当前官方工具包核查基线：版本 2.0.0；ZIP SHA-256 为 `cf557e5a022e4297892f39768132855154232efdedeb726b2845450ccd70e1b3`，37,575 字节。已有基线不重复下载或运行；临近提交若规则变化再另行核对。
